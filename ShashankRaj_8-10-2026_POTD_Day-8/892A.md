# Problem Name - Greed - 892A

# Description

I firstly sorted the given capacities of all cans in ascending order and then calcuated the combined capacity of the two largest cans. Then i claculated total sum of the remaining amount of cola in all cans and compared it against the sum of the capacity of two largest cans and printed YES and NO accordingly

# Code

```java
import java.util.*;
public class Greed {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        long remSum=0;
        for(int i=0;i<n;i++){
            remSum+=sc.nextInt();
        }
        int canCapacity[]=new int[n];
        for(int i=0;i<n;i++){
            canCapacity[i]=sc.nextInt();
        }
        Arrays.sort(canCapacity);
        long totalOfTwo=canCapacity[n-1]+canCapacity[n-2];
        if(remSum<=totalOfTwo){ //Checking if the total remaining amount of drink is less than or equal to the sum of the two largest can capacities
            System.out.println("YES");
        }
        else{
            System.out.println("NO");
        }
    }
}

```

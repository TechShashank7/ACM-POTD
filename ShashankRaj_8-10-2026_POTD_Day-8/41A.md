# Problem Name - Translation - 41A

# Description

I just compared the given word string with the reverse of the other given string and if they are equal i printed YES otherwise NO.

# Code

```java
import java.util.*;
public class Translation {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        String t=sc.next();
        if(s.equals(new StringBuilder(t).reverse().toString())){
            System.out.println("YES");
        }
        else{
            System.out.println("NO");
        }
    }
}

```

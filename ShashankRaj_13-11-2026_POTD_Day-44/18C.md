# Problem Name - Stripe - 18C

# Description
I first calculated the sum of all the elements. Then I created a prefix sum array to store the sum of all the elements from the start till the current respective index. 
Now if the sum of all the elements is S, then we are looking for a condition where the sum of all the elements till the current respective index (let's say P) shall be equal to the sum of the remaining elements, i.e. S - P. Therefore, P = S - P → P = S/2. Hence, we can conclude that the total sum shall be even. If it's odd, then we can't get any desired combination from the given elements and we print 0 and return from there. Otherwise, I count how many times I see `s/2` in the prefix sum array, and print it

# Code

```java
import java.util.*;
public class Stripe {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int arr[]=new int[n];
        int sum=0; // Some of all the elements
        int prefixSum[]=new int[n]; // An array to store the sum of all the elements from starting till current respective index 
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
            prefixSum[i]=sum+arr[i];
            sum+=arr[i];
        }
        if(sum%2!=0){ // If the sum of all the elements is S, then we are looking for a condition where the sum of all the elements till the current respective index (let's say P) shall be equal to the sum of the remaining elements, i.e. S - P. Therefore, P = S - P → P = S/2. Hence, we can conclude that the total sum shall be even. If it's odd, then we can't get any desired combination from the given elements. 
            System.out.println(0);
            return;
        }
        int count=0; // Count of all appropriate combinations 
        for(int i=0;i<n-1;i++){
            if(prefixSum[i]==sum/2){
                count++;
            }
        }
        System.out.println(count);
    }
}

```

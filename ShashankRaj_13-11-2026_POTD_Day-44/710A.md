# Problem Name - King Moves - 710A

# Description

Firstly, I check if the king is at the corner of the board or not. If yes, then I put 3, since only 3 moves are allowed: one horizontal, one vertical, and one diagonal. If it's not at a corner, then I check if it's at an edge except the corner. If yes, then I print 5, since only 5 moves are allowed. That is 2 horizontal/vertical, 1 horizontal/vertical, and 2 diagonals. If not, then I print 8, because if the king is not at any corner or edge, then it's in between somewhere on the board. In this case, there are 8 possible moves : 2 horizontal, 2 vertical, and 4 diagonals. 

# Code

```java
import java.util.*;
public class KingMoves {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        if((s.charAt(0)=='a' && s.charAt(1)=='1') || (s.charAt(0)=='a' && s.charAt(1)=='8') || (s.charAt(0)=='h' && s.charAt(1)=='1') || (s.charAt(0)=='h' && s.charAt(1)=='8')){ // King is at the corners of the board 
            System.out.println(3);
        }
        else if(s.charAt(0)=='a' || s.charAt(0)=='h' || s.charAt(1)=='1' || s.charAt(1)=='8'){ // King is at an edge but not a corner of the board. 
            System.out.println(5);
        }
        else{
            System.out.println(8);
        }
    }
}

```

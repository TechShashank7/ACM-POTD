# Problem Name - Subtractions - 267A

# Description

For every pair, i checked which one's greater and then i decreased the greater one in multiples of the smaller one till its greater and kept updating the 'count' variable which is keeping the track of total no. of operations, with total no. of divisions. If both numbers are equal then i just make the first one 0 and increment count by 1. I kept repeating this procedure for every pair and at last printed the 'count' variable.

# Code

```java
import java.util.*;
public class Subtractions{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        long arr[][]=new long[n][2];
        for(int i=0;i<n;i++){
            for(int j=0;j<2;j++){
                arr[i][j]=sc.nextLong();
            }
        }
        for(int i=0;i<n;i++){
            long count=0;
            while(arr[i][0]!=0 && arr[i][1]!=0){
                if(arr[i][0]>arr[i][1]){
                    count+=arr[i][0]/arr[i][1];
                    arr[i][0]%=arr[i][1];
                }
                else if(arr[i][1]>arr[i][0]){
                    count+=arr[i][1]/arr[i][0];
                    arr[i][1]%=arr[i][0];
                }
                else{
                    arr[i][0]=0;
                    count++;
                }
            }
            System.out.println(count);
        }
    }
}

```

# Problem Name - Square Earth? - 57A

# Description

I imagined the whole perimeter of the square being laid as a line since both the given points are lying on the side so now they will lie in a straight line. Now i calculated the distances of both points from origin considering clockwise direction. Then i calculated teh same in anti-clockwise direction which is just the 4n - difference we got via clockwise one. Then i printed the minimum of both distances.

# Code

```java
import java.util.*;
public class SquareEarth { // Calculating distance from origin along the sides of square in clockwise direction
    public static int distance(int x, int y, int n){
        if(0<=x && x<=n && y==0){
            return x;
        }
        else if(x==n && 0<=y && y<=n){
            return n+y;
        }
        else if(0<=x && x<=n && y==n){
            return 2*n+(n-x);
        }
        return 3*n+(n-y);
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int x1=sc.nextInt();
        int y1=sc.nextInt();
        int x2=sc.nextInt();
        int y2=sc.nextInt();
        int d1=distance(x1, y1, n);
        int d2=distance(x2, y2, n);
        int diff=Math.abs(d1-d2); // Distance between both points in clockwise direction
        System.out.println(Math.min(diff, 4*n-diff)); // Printing the minimum distance among the clockwise and anti-clockwise direction
    }
}

```

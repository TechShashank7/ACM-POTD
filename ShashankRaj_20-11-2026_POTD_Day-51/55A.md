# Problem Name - Flea Travel - 55A

# Description

Looking at a few example n, its evident that for all hassocks to be visited, n shall be a power of 2. Therefore i just checked if n is an power of 2 or not via bitwise operations. If yes , i printed "YES" otherwise "NO"

# Code

```java
import java.util.*;
public class FleaTravel {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        System.out.println((n&(n-1))==0 ? "YES" : "NO"); // Checking if n is a power of 2 or not
    }
}

```

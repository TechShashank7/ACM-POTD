# Problem Name - Indian Summer - 44A

# Description

I stored all n combinations of colour and species of leaves in a set and printed its size due to which any repeated combination is counted just once.

# Code

```java
import java.util.*;
public class IndianSummer {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        Set<String> set=new HashSet<>();
        for(int i=0;i<n;i++){
            set.add(sc.next()+" "+sc.next());
        }
        System.out.println(set.size());
    }
}

```

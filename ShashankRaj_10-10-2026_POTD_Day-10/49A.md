# Problem Name - Sleuth  - 49A

# Description

I first removed any non-alphabet character from the sentence starting from end and stopping at the index when we found the first alphabet else our pointer i crosses below 0 in case there is no alphabet in sentence. Then i checked if i>=0 to check if sentence even has any alphabet or not and if then we check if the last character is an vowel and we print YES in that case otherwise NO.

# Code

```java
import java.util.*;
public class Sleuth{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.nextLine().toLowerCase();
        int i=s.length()-1;
        while(i>=0 && !Character.isLetter(s.charAt(i))){ //Starting from end and removing any non-alphabet character and stopping when we find the first alphabet
            i--;
        }
        if (i >= 0 && "aeiouy".indexOf(s.charAt(i)) >= 0) { //if i<0 then there is no alphabet existing in sentence. And if the last alphabet is vowel then it must be in in "aeiouy" array and therefore .indexOf will return any no. between 0-5 otherwise if its a consonant
            System.out.println("YES");
        } else {
            System.out.println("NO");
        }
    }
}

```

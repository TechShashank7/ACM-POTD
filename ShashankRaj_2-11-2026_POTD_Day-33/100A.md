# Problem Name - Carpeting the Room - 100A

# Description

I calculated the minimum number of side-by-side carpets needed to cover the room's dimension using ceiling division. Then i checked if the squared total count is less than or equal to $k$ and outputs YES or NO accordingly.

# Code

```pike
int main() {
    int n, k, m;
    sscanf(Stdio.stdin->gets(), "%d%d%d", n, k, m);
    n = (n + m - 1) / m;
    write(n * n <= k ? "YES\n" : "NO\n");
    return 0;
}

```

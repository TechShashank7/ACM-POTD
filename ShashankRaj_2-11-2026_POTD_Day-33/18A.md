# Problem Name - Triangle - 18A

# Description

I first implemented a function to check if the given coordinates could give right triangle under any possible combination by checking using pythagoras theorem. Also, to avoid coincident  points creating zero-length values of sides, i checked them beforehand for all 3 cases and returned false from there indeed if it was. Now for right triangle check, thsi function ofcourse works properly. For almost-right triangle check, i made all 12 cases by shifting coordinates by 1 and applied the isRight function on all of them to check if any one of them gives right triangle now after shifting by 1 unit, under any possible cases. If neither of the case exists then the the points cant form right triangle.

# Code

```java
import java.util.Scanner;

public class Triangle {
    public static boolean isRight(double x1, double y1, double x2, double y2, double x3, double y3) { // To check if the given coordinates give a right triangle

        //Avoiding coincident points creating zero-length sides
        if (x1 == x2 && y1 == y2) return false;
        if (x1 == x3 && y1 == y3) return false;
        if (x2 == x3 && y2 == y3) return false;

        // Applying pythagoras therorem on all combinations and checking if any of them gives a right triangle
        return (x2 - x1) * (x3 - x1) + (y2 - y1) * (y3 - y1) == 0
            || (x1 - x2) * (x3 - x2) + (y1 - y2) * (y3 - y2) == 0
            || (x1 - x3) * (x2 - x3) + (y1 - y3) * (y2 - y3) == 0;
        }

    public static void main(String[] args) {
        try (Scanner sc = new Scanner(System.in)) {
            double x1 = sc.nextDouble();
            double y1 = sc.nextDouble();
            double x2 = sc.nextDouble();
            double y2 = sc.nextDouble();
            double x3 = sc.nextDouble();
            double y3 = sc.nextDouble();

            if(isRight(x1, y1, x2, y2, x3, y3)){ // Checking for possiblity of right triangle
                System.out.println("RIGHT");
            }
            else if (isRight(x1 + 1, y1, x2, y2, x3, y3) || isRight(x1 - 1, y1, x2, y2, x3, y3) || isRight(x1, y1 + 1, x2, y2, x3, y3) || isRight(x1, y1 - 1, x2, y2, x3, y3) || isRight(x1, y1, x2 + 1, y2, x3, y3) || isRight(x1, y1, x2 - 1, y2, x3, y3) || isRight(x1, y1, x2, y2 + 1, x3, y3) || isRight(x1, y1, x2, y2 - 1, x3, y3) || isRight(x1, y1, x2, y2, x3 + 1, y3) || isRight(x1, y1, x2, y2, x3 - 1, y3) || isRight(x1, y1, x2, y2, x3, y3 + 1) || isRight(x1, y1, x2, y2, x3, y3 - 1)) { // Checking for right triangle from all 12 cases of shifting coordinates by 1
                System.out.println("ALMOST");
            }
            else{ // None of conditions give right triangle
                System.out.println("NEITHER");
            }
        }
    }
}
```

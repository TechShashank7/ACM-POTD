# Problem Name - Coins - 47B

# Description

I created a hashmap to store the count of A,B,C giving them a numerical value to compare with. With all 3 given comparison statements, i incremented teh count of one that's greater than the other. Then i checked for all 6 cases for comparisons between A,B,C and printed teh order accordingly. Also for the contradiction cases i.e. where count of any two or more becomes same, i printed "Impossible".

# Code

```java
import java.util.*;
public class Coins {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        HashMap<Character, Integer> map=new HashMap<>();
        map.put('A', 0);
        map.put('B', 0);
        map.put('C', 0);
        for(int i=0;i<3;i++){
            String s=sc.next();
            if(s.charAt(1)=='>'){ // Incrementing count of the bigger character
                map.put(s.charAt(0), map.getOrDefault(s.charAt(0), 0)+1);
            }
            else{
                map.put(s.charAt(2), map.getOrDefault(s.charAt(2), 0)+1);
            }   
        }
        int A=map.get('A'), B=map.get('B'), C=map.get('C');
        if(A>B && B>C){
            System.out.println("CBA");
        }
        else if(A>C && C>B){
            System.out.println("BCA");
        }
        else if(B>A && A>C){
            System.out.println("CAB");
        }
        else if(B>C && C>A){
            System.out.println("ACB");
        }
        else if(C>A && A>B){
            System.out.println("BAC");
        }
        else if(C>B && B>A){
            System.out.println("ABC");
        }
        else{ // When two or more characters have same count in map
            System.out.println("Impossible");
        }
    }
}

```

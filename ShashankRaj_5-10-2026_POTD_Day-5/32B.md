# Problem Name - Borze - 32B

# Description

Firstly i initialised a pointer i with 0 to iterate over the given ternary numeric notation string. If we find '.' then we print 0 for it and increment i by 1. If we find '-' then we check if succesive character is whether '.' or '-' according to which we print 1 or 2 and then we increment i by 2.

# Code

```java
import java.util.*;
public class Borze {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        int i=0;
        while(i<s.length()){
            if(s.charAt(i)=='.'){
                System.out.print("0");
                i++;
            }
            else{
                if(s.charAt(i+1)=='.'){
                    System.out.print("1");
                }
                else{
                    System.out.print("2");
                }
                i+=2;
            }
        }
    }
}

```

# Problem Name - Pasha and Hamsters - 421A

# Description

In every iteration i just chhecked i fthe index of current apple is in the preference of Arthur or Alexander. If it's in Arthur's preference then i printed 1 otherwise 2 for Alexander.

# Code

```java
import java.util.*;
public class PashaAndHamsters{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int a=sc.nextInt();
        int b=sc.nextInt();
        List<Integer> list1=new ArrayList<>();
        List<Integer> list2=new ArrayList<>();
        for(int i=0;i<a;i++){
            list1.add(sc.nextInt());
        }
        for(int i=0;i<b;i++){
            list2.add(sc.nextInt());
        }
        for(int i=1;i<=n;i++){
            if(list1.contains(i)){ //Arthur likes this apple
                System.out.print(1+" ");
            }
            else{ //Alexander likes this apple
                System.out.print(2+" ");
            }
        }
    }
}

```

# Problem Name - Candy Bags - 334A

# Description

I used the 2-pointer approach here. I initialised left with starting bag and right with last bag. Using the fact that if we form pairs using these 2 pointers, we'll always have the sum of candies in a pair as n^2+1, i started a loop and also for each brother, there will be total n/2 pairs. Using this i firstly gave bag at index left and right to first brother, then incremented left and decremented 1 and kept giving pairs to the same brother until he has n/2 pairs with him and then moved to next brother and continued the same until finally left becomes n/2 and right becomes n/2+1 and the pair gets assigned to the last brother

# Code

```java
import java.util.*;
public class CandyBags {
    public static  void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int left=1, right=n*n;
        for(int i=0;i<n;i++){
            for(int j=0;j<n/2;j++){
                System.out.print(left+" "+right+" ");
                left++;
                right--;
            }
            System.out.println();
        }
    }
}
```

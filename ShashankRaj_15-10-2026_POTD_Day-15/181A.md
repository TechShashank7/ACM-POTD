# Problem Name - Series of Crimes  - 181A

# Description

I iterated over the given grid and for every * found i did its row's and column's XOR and the final answer gave our required position for 4th *. I actually used a property of XOR here i.e. XOR of a number with itself gives zero, and XOR of a number with zero gives the number back. 

# Code

```java
import java.util.*;
public class SeriesOfCrime {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        int missingRow = 0;
        int missingCol = 0;
        for (int i = 1; i <= n; i++) { // Iterate through the grid
            String s=sc.next();
            for (int j = 1; j <= m; j++) {
                if (s.charAt(j-1) == '*') { // If a robbery location is found, XOR its coordinates
                    missingRow ^= i;
                    missingCol ^= j;
                }
            }
        }        
        System.out.println(missingRow + " " + missingCol);
    }
}
```

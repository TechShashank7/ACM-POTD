# Problem Name - Valuable Resources  - 485B

# Description

I iterated over all the points to find the minimum X,Y and maximum X,Y because (maximum of X - minimum of X) will give us minimum width and similarly (maximum of Y - minimum of Y) will give us minimum height. Afterwards, the maximum of this minimum height and width shall give us the side of required square since the square should accomodate both these lengths. And therefore i returned the area of the square with respect to this side length.

# Code

```java
import java.util.*;
public class ValuableResources {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        long arr[][]=new long[n][2];
        long maxX=Integer.MIN_VALUE;
        long minX=Integer.MAX_VALUE;
        long maxY=Integer.MIN_VALUE;
        long minY=Integer.MAX_VALUE;
        for(int i=0;i<n;i++){
            for(int j=0;j<2;j++){
                arr[i][j]=sc.nextInt();
            }
        }
        for(int i=0;i<n;i++){
            maxX=Math.max(maxX, arr[i][0]);
            minX=Math.min(minX, arr[i][0]);
            maxY=Math.max(maxY, arr[i][1]);
            minY=Math.min(minY, arr[i][1]);
        }
        long ans=Math.max(maxX-minX, maxY-minY);
        System.out.println(ans*ans);
    }
}

```

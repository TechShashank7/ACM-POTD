# Problem Name - Football   - 43A

# Description

I first created a hash map and stored the frequency of the number of goals scored by each team. Then i printed the one with highest count 

# Code

```java
import java.util.*;
public class Football {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        HashMap<String, Integer> map=new HashMap<>(); //Maintaining the count of how many goald a team scored
        for(int i=0;i<n;i++){
            String s=sc.next();
            map.put(s, map.getOrDefault(s,0)+1);
        }
        System.out.println(Collections.max(map.entrySet(), Map.Entry.comparingByValue()).getKey()); //Printing the team name with highest no. of goals
    }
}

```

# Problem Name - Is your horseshoe on the other hoof?   - 228A

# Description

I first stored frequency of every shoe colour and then found the total no. of duplicates since that's the no. we indeed need to find to replace with new ones

# Code

```java
import java.util.*;
public class Is_your_horseshoe_on_the_other_hoof {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        Map<Integer, Integer> map=new HashMap<>();
        for(int i=0;i<4;i++){
            int n=sc.nextInt();
            map.put(n, map.getOrDefault(n, 0)+1); //Storing count of every shoe colour available
        }
        int count=0;
        for(int i : map.values()){
            if(i>1){
                count+=i-1; //Adding the duplicates since that's the no. we need to replace with new ones
            }
        }
        System.out.println(count);
    }
}

```

# Problem Name - Bear and Poker - 573A

# Description

For every element i removed all factors of 2 first and then factors of 3 too and for comparing this final no. with the final no. we'll get after doing similar operations on next element, we store it in base variable. The moment it finds if current element's final no. after those operations doesn't matches with previous element's final no. after those operations, we print NO and return. Otherwise if loop successfully gets cleared then we print YES since the final no. for all elements is same and therefore all elements can be made equal via doubling and tripling any no. of times.

# Code

```java
import java.util.*;
public class BearAndPoker {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        long base=-1;
        for(int i=0;i<n;i++){
            long x=sc.nextLong();
            while (x % 2 == 0) { //Removing all factors of 2
                x /= 2;
            }
            while (x % 3 == 0) { //Removing all factors of 3
                x /= 3;
            }

            if (base == -1) {
                base = x; //Storing the final no. in base to check with next element
            } else if (x != base) {
                System.out.println("NO");
                return;
            }
        }
        System.out.println("YES");
    }
}

```

# Problem Name - Young Physicist - 69A

# Description

I caluclated sum of X,Y and Z coordinates of all the points and if all of them are zero so resultant of all forces is zero and hence body is in equilibrium otherwise not. 

# Code

```java
import java.util.*;
public class YoungPhysicist {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int arr[][]=new int[n][3];
        int sumX=0,sumY=0,sumZ=0;  
        for(int i=0;i<n;i++){
            for(int j=0;j<3;j++){
                arr[i][j]=sc.nextInt();
            }
        }
        for(int i=0;i<n;i++){
            sumX+=arr[i][0]; //Tracking sum of X-coordinates
            sumY+=arr[i][1]; //Tracking sum of Y-coordinates
            sumZ+=arr[i][2]; //Tracking sum of Z-coordinates
        }
        System.out.println(sumX==0 && sumY==0 && sumZ==0 ? "YES" : "NO"); //If resultant of all respective coordinates of all points is zero then body is in equilibrium otherwise not
    }
}

```

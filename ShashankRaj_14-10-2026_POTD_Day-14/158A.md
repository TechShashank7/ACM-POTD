# Problem Name - Next Round  - 158A

# Description

I iterated over the given sorted list of elements and checked for just 2 things i.e. if they are greater than kth element as well if they are +ve. Then i printed the count of elements satisfying both conditions.

# Code

```java
import java.util.*;
public class NextRound {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int k=sc.nextInt();
        int arr[]=new int[n];
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
        }
        int count=0;
        for (int i : arr) { // Counting the no. of elements greater than the one at kth position and checing if they are +ve as well
            if (i >= arr[k-1] && i > 0) {
                count++;
            }
        }
        System.out.println(count);
    }
}

```

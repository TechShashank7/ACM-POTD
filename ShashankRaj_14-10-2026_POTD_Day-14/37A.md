# Problem Name - Towers  - 37A

# Description

I maintained a hash map and stored the frequency of all the given tower heights. Then I calculated the maximum height from this hash map and printed it as its the height of the tallest tower and the size of map signifies the no. of towers

# Code

```java
import java.util.*;
public class Towers {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int arr[]=new int[n];
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
        }
        HashMap<Integer, Integer> map=new HashMap<>();
        for(int i=0;i<n;i++){ //Storing frequency of all tower heights 
            map.put(arr[i], map.getOrDefault(arr[i], 0)+1);
        }
        int max=0;
        for(int i : map.values()){ 
            max=Math.max(max, i); //Finding the tower with maximum height 
        }
        System.out.println(max+" "+map.size());
    }
}

```

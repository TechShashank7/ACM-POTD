# Problem Name - Football - 96A

# Description

I ran a loop over given string and in every iteration, i checked if the current number is same as the last one , for which we are tracking using a variable 'last'. If yes then i increment 'count' variable which is keepig track of the consecutive occurences of a same number. Also i kept updating 'last' with current number before ending current iteration. If at anytime , this iteration exceeds or gets equal to 7 then i print "YES" since condition is dangerous and exit the code. If the number gets changed in any iteration and becomes differnt then 'last', then i reset 'count' to 0. If the loop passes succesfully then i printed "NO" since condition is safe.

# Code

```java
import java.util.*;
public class FootballA {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        int count=1;
        char last=s.charAt(0);
        for(int i=1;i<s.length();i++){ 
            if(s.charAt(i)==last){
                count++;
                if(count>=7){
                    System.out.println("YES");
                    return;
                }
            }
            else{
                count=1;
            }
            last=s.charAt(i);
        }
        System.out.println("NO");
    }
}

```

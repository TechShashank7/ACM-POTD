# Problem Name - IQ Test - 25A

# Description

There can be just two cases i.e. when all the numbers are even and just a single odd and vice-versa. 
Now, the majority of either even or odd elements can be decided from checking first 3 numbers indeed. If there are more even numbers than odd among first 3 numbers there will be all even numbers in the whole given list and vice-versa
In case of even majority, i ran a loop over all numbers, find that single odd number and print it.
Vice-versa for odd majority.

# Code

```java
import java.util.*;
public class IQTest {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int arr[]=new int[n];
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
        }
        int even=0, odd=0;
        for(int i=0;i<3;i++){ // The majority of either even or odd elements can be decided from checking first 3 numbers indeed. If there are more even numbers than odd among first 3 numbers there will be all even numbers in the whole given list and vice-versa
            if(arr[i]%2==0){
                even++;
            }
            else{
                odd++;
            }
        }
        if(even>odd){ // If there are more even numbers than odd then printing that single odd number
            for(int i=0;i<n;i++){
                if(arr[i]%2!=0){
                    System.out.println(i+1);
                    break;
                }
            }
        }
        else{ // If there are more odd numbers than even then printing that single even number
            for(int i=0;i<n;i++){
                if(arr[i]%2==0){
                    System.out.println(i+1);
                    break;
                }
            }
        }
    }
}

```

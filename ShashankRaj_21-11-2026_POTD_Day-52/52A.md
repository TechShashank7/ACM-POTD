# Problem Name - 123-Sequence - 52A

# Description

I stored the frequency of all the integers 1,2,3 in an array and then sorted it so the end element contains the maximum frequency. Now i printed the sum of all the other integer's frequencies since we'll need to replace them all to match the one with maximum frequency.

# Code

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;
public class OneTwoThree_Sequence {
    public static void main(String[] args) throws IOException{
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        
        int[] arr = new int[3];
        StringTokenizer st = new StringTokenizer(br.readLine());
        
        for (int i = 0; i < n; i++) {
            arr[Integer.parseInt(st.nextToken()) - 1]++;
        }
        Arrays.sort(arr);
        System.out.println(n-arr[2]);
    }
}

```

# Problem Name - Fortune Telling - 59B

# Description

It is obvious that the result will be 'Love' only when the sum of all the petals of all flowers in the bouquet is odd otherwise, it will be "Doesn't love" . I first calculated the sum of all the petals of all the flowers in the bouquet, and then I sorted the array. Now, I checked if the calculated sum is even or not. If it's even, then I subtracted the smallest odd element, that is, arr[0], to make the sum odd again. Afterwards, I again checked if the sum is still odd. If it is, then there is no flower in the bouquet with odd petals, and therefore the result can never be 'Love' so printed 0. Otherwise, I print sum. 

# Code

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;
public class FortuneTelling{
    public static void main(String[] args) throws IOException{
        BufferedReader br=new BufferedReader(new InputStreamReader(System.in));
        int n=Integer.parseInt(br.readLine().trim());
        int arr[]=new int[n];
        StringTokenizer st=new StringTokenizer(br.readLine());
        for(int i=0;i<n;i++){
            arr[i]=Integer.parseInt(st.nextToken());
        }
        int sum=Arrays.stream(arr).sum();
        Arrays.sort(arr);
        if(sum%2==0){ // If the sum of all the petals in the boquet is even, then subtract the smallest odd element to make it odd. 
            for(int i : arr){
                if(i%2!=0){
                    sum-=i;
                    break;
                }
            }
        }
        System.out.println(sum%2==0 ? 0 : sum); // If the sum is still odd, then there is no flower in the boquet with odd petals, and therefore the result can never be 'Love', so print 0 otherwise sum.
    }
}
```

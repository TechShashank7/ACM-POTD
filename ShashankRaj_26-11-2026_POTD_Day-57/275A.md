# Problem Name - Lights Out - 275A

# Description

I started with a 'lights' array with every light as ON and stored the number of toggles for each light in a 'toggles' array. Then i iterated through every light and checked if it is a corner, edge or center light and calculated the final state of that light using the formula (1 - (toggles of that light + toggles of its adjacent lights) % 2) and updated the state inside 'lights' array. Finally i printed the final state of all lights.

# Code

```java
import java.util.*;
public class LightsOut {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int size=3;
        int lights[][]={{1,1,1}, {1,1,1}, {1,1,1}};
        int toggles[][]=new int[3][3];
        for(int i=0;i<size;i++){
            for(int j=0;j<size;j++){
                toggles[i][j]=sc.nextInt();
            }
        }
        for(int i=0;i<size;i++){
            for(int j=0;j<size;j++){
                if(i==0 && j==0){ // Top-left corner
                    lights[i][j]=1-(toggles[i][j]+toggles[i][j+1]+toggles[i+1][j])%2;
                }
                else if(i==0 && j==(size-1)){ // Top-right corner
                    lights[i][j]=1-(toggles[i][j]+toggles[i][j-1]+toggles[i+1][j])%2;
                }
                else if(i==(size-1) && j==0){ // Bottom-left corner
                    lights[i][j]=1-(toggles[i][j]+toggles[i-1][j]+toggles[i][j+1])%2;
                }
                else if(i==(size-1) && j==(size-1)){ // Bottom-right corner
                    lights[i][j]=1-(toggles[i][j]+toggles[i-1][j]+toggles[i][j-1])%2;
                }
                else if(i==0){ // Top edge
                    lights[i][j]=1-(toggles[i][j]+toggles[i][j-1]+toggles[i][j+1]+toggles[i+1][j])%2;
                }
                else if(i==(size-1)){ // Bottom edge
                    lights[i][j]=1-(toggles[i][j]+toggles[i][j-1]+toggles[i][j+1]+toggles[i-1][j])%2;
                }
                else if(j==0){ // Left edge
                    lights[i][j]=1-(toggles[i][j]+toggles[i-1][j]+toggles[i+1][j]+toggles[i][j+1])%2;
                }
                else if(j==(size-1)){ // Right edge
                    lights[i][j]=1-(toggles[i][j]+toggles[i-1][j]+toggles[i+1][j]+toggles[i][j-1])%2;
                }
                else{ // Center
                    lights[i][j]=1-(toggles[i][j]+toggles[i-1][j]+toggles[i+1][j]+toggles[i][j-1]+toggles[i][j+1])%2;
                }
            }
        }
        for(int i=0;i<size;i++){
            for(int j=0;j<size;j++){
                System.out.print(lights[i][j]);
            }
            System.out.println();
        }
    }
}

```

# Problem Name - Alice, Bob and Chocolates  - 6C

# Description

I first initialized the variables `timeA` and `timeB` to keep track of the time taken by Alice and Bob to eat their respective chocolates. Then I started a loop, initializing two pointers: `i` from 0 and `j` from the end index i.e. n - 1, for Alice and Bob. In every iteration, I check if the time taken by Alice to eat the chocolate is less than or equal to the time taken by Bob to eat the chocolate. If it is, then I add the current given time in the array to `timeA` and increase the count of chocolates eaten by Alice by 1. Otherwise, I add this time to `timeB` and increment the count of chocolates eaten by Bob by 1. 

# Code

```java
import java.util.*;
public class AliceBobAndChocolate{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int arr[]=new int[n];
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
        }
        int alice=0, bob=0, timeA=0, timeB=0, i=0, j=n-1;
        while(i<=j){
            if(timeA<=timeB){
                timeA+=arr[i++];
                alice++;
            }
            else{
                timeB+=arr[j--];
                bob++;
            }
        }
        System.out.println(alice+" "+bob);
    }
}

```

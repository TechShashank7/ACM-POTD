# Problem Name - Maximum Increase - 702A

# Description

I initialize the `count` variable with 1 and the `max` variable with 1. Then I started a loop from the second element in the array. In every iteration, I kept checking if this element is greater than its preceding one. If it is, then I increase the `count`. Otherwise, I reset it to 1, and in every iteration, I kept updating the `max` variable. At last, I printed the `max` variable that is storing the count of the required subarray length. 

# Code

```java
import java.util.*;
public class MaximumIncrease{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        long arr[]=new long[n];
        int max=1;
        int count=1;
        for(int i=0;i<n;i++){
            arr[i]=sc.nextLong();
        }
        for(int i=1;i<n;i++){
            if(arr[i]>arr[i-1]){ // If the current element is greater than the last one, then increase the count. Otherwise, reset it to 1. 
                count++;
            }
            else{
                count=1;
            }
            max=Math.max(max, count);
        }
        System.out.println(max);
    }
}

```

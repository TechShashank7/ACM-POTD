# Problem Name - Letter - 43B

# Description

I first stored the frequency of all the letters in the first string in a hash map, except the space character. Then, for every letter in the second string, I check if its count in the first string is at least equivalent to that or more than that. Otherwise, if any one of the letters fails to fulfill this condition, then we print "NO". Otherwise, if all the characters pass this condition, then we print "YES". 

# Code

```java
import java.util.*;
public class B_Letter {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s1=sc.nextLine();
        String s2=sc.nextLine();
        Map<Character, Integer> map=new HashMap<>();
        for(char i : s1.toCharArray()){
            if(i!=' '){
                map.put(i, map.getOrDefault(i, 0)+1); //Storing frequency of all letters in the first string except space 
            }
        }
        for(char i : s2.toCharArray()){ //For every letter in the second string, except space, we check if it exists. If the count of it exists equivalentl to that in string 1, then we decrement its count in the hash map. Otherwise, we exit from here indeed and print "NO". 
            if(i!=' '){
                if(map.getOrDefault(i, 0)==0){ 
                    System.out.println("NO");
                    return;
                }
                map.put(i, map.get(i)-1);
            }
        }
        System.out.println("YES"); //If the loop successfully got past without printing "NO", then for every letter in the second string, there is an equal or greater amount, of that letter in the first string. 
    }
}

```

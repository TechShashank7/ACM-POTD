# Problem Name - George and Accommodation  - 467A

# Description

With every room's current people living, p and max capacity, q given, i calculated the diff of p and q to check whether the room has space for both George and his friend and if it has ten i increment count variable which is keeping track of total such rooms and then i print it at last.

# Code

```java
import java.util.*;
public class GeorgeAndAccomodation{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int count=0;
        for(int i=0;i<n;i++){
            int p=sc.nextInt();
            int q=sc.nextInt();
            if(q-p>=2){
                count++;
            }
        }
        System.out.println(count);
    }
}

```

# Problem Name - Sereja and Bottles - 315A

# Description

I solved the problem in two passes by first using a frequency array `openerCount` to tally exactly how many times each brand can be opened by the entire collection. In the second pass, it evaluates each bottle to see if its brand has at least one available opener recorded in that array. To prevent a bottle from opening itself, the logic enforces that if a bottle's brand and opener match, its brand's opener count must be greater than one, indicating a *second* bottle is present to do the opening. Any bottle that fails to meet these conditions is added to the final unopened count.

# Code

```java
import java.util.*;
public class SerejaAndBottles {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int a[]=new int[n];
        int b[]=new int[n];
        int openerCount[]=new int[1001];
        for(int i=0;i<n;i++){
            a[i]=sc.nextInt();
            b[i]=sc.nextInt();
            openerCount[b[i]]++; // Increment the count of available openers for brand b[i]
        }
        int unopenedCount=0;
        for(int i=0;i<n;i++){ // Check each bottle to see if it can be opened
            if(a[i]==b[i]){ // It opens its own brand. We need at least one OTHER bottle to open it, meaning the openerCount must be > 1.
                if(openerCount[a[i]]<=1){
                    unopenedCount++;
                }
            }
            else{ // It opens a different brand. We just need any bottle in the collection that opens its brand.
                if(openerCount[a[i]]==0){
                    unopenedCount++;
                }
            }
        }
        System.out.println(unopenedCount);
    }
}

```

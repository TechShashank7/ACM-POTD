# Problem Name - Sereja and Mugs - 426A

# Description

I just checked if the sum of the volumes of the water in all teh cups except the largest one poured in the empty cup doesnt overfills it. Because there are exactly n-1 friends playing it so one glass will be left so why not the leave the largest one indeed. So if the sum of the volumes of water in all the cups except the largest one is less than or equal than the given empty cup volume then no one will lose otherwise will.

# Code

```java
import java.util.*;
public class SerejaAndMugs{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int s=sc.nextInt();
        int arr[]=new int[n];
        int sum=0;
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
            sum+=arr[i];
        }
        Arrays.sort(arr);
        if(sum-arr[n-1]<=s){
            System.out.println("YES");
        }
        else{
            System.out.println("NO");
        }
    }
}

```

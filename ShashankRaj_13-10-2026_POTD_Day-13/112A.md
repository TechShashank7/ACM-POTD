# Problem Name - Petya and Strings  - 112A

# Description

I firstly converted both strbgs to lowercase and then firstly chacked if they are equal and if they are then printed 0 and exited. Otherwise i checked s1>s2 using .compareTo method which will return +ve int for s1>s2 and -ve  for vice-versa, and then printed 1 and -1 accordingly.

# Code

```java
import java.util.*;
public class PetyaAndStrings{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s1=sc.next().toLowerCase();
        String s2=sc.next().toLowerCase();
        if(s1.equals(s2)){
            System.out.println(0);
            return;
        }
        System.out.println(s1.compareTo(s2)<0 ? -1 : 1);
    }
}

```

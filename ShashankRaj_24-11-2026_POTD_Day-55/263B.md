# Problem Name - Squares - 263B

# Description

I first sorted the array and straightforwardly printed the coordinates as (First square's border lying in the rightmost window of K length, 0). Also when k>n, no coordinate can exist in such condition so i printed -1.

# Code

```java
import java.util.*;
public class Squares {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int k=sc.nextInt();
        if(n<k){ 
            System.out.println(-1);
            return;
        }
        long arr[]=new long[n];
        for(int i=0;i<n;i++){
            arr[i]=sc.nextLong();
        }
        Arrays.sort(arr);
        System.out.println(arr[n-k]+" "+0);
    }
}

```

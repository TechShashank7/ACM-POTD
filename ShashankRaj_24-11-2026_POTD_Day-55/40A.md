# Problem Name - Find Color - 40A

# Description

I first calculated the euclidean distance of (x,y) from origin and then did square root of it which gave us indeed the radius of the imaginary circle having centre as (0,0) and (x,y) on its boundary.
Now if either of the abcissa or ordinate is 0 i.e. point is on an axis or if the radius is exactly equal to the euclidean distance between then point is on an circle's border. In either cases, the point will be lying in a black-coloured area.
If x and y are either both +ve or both -ve then point is in 1st or 2nd quadrant otherwise 3rd or 4th quadrant. If in 1st or 3rd quadrant, an even radius will result in point being in a black-coloured plane otherwise white-colured plane and vice-versa if in 2nd or 4th quadrant.

# Code

```java
import java.util.*;
public class FindColor {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int x=sc.nextInt();
        int y=sc.nextInt();
        int d=x*x+y*y;
        int r=(int)Math.sqrt(d); // Radius of the circle having centre as (0,0) and (x,y) on its boundary
        if(x==0 || y==0 || r*r==d){ // On an axis or directly on the circle
            System.out.println("black");
            return;
        }
        if((x>0 && y>0) || (x<0 && y<0)){ // 1st/3rd quadrant
            System.out.println(r%2==0 ? "black" : "white");
        }
        else{ // 2nd/4th quadrant
            System.out.println(r%2==0 ? "white" : "black");
        }
    }
}

```

# Problem Name - Domino Piling  - 50A

# Description

I gone with the most straightforward approach here i.e. printing the division of N X M total area by given 2 X 1 tiles which will give us the maximum no. of such tiles which could be fit inside the board

# Code

```java
import java.util.*;
public class DominoPiling{
    public static void main(String [] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        System.out.println((n*m)/2);
    }
}

```

# Problem Name - Holidays - 670A

# Description

I first initialised both max and min with 2*(n/7) since each week of 7 days have 2 days off. Then for case when n is a 7's multiple, this max and min is the required max and min working days. For cases when not then for max, we consider the remaining days start with off days while for min, we consider the remaining days start with working days.

# Code

```java
import java.util.*;
public class Holidays {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int max=2*(n/7),min=2*(n/7); //Initialising both max and min with 2*(n/7) since each week of 7 days have 2 days off
        int rem=n%7;
        if(rem==0){ 
            System.out.println(min+" "+max);
            return;
        }
        max += Math.min(rem, 2); //if the rem is/are off day/days
        min += Math.max(0, rem-5); //if the rem is/are working days
        System.out.println(min+" "+max);
    }
}

```

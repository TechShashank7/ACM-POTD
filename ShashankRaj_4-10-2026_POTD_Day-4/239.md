# Problem Name - Two Bags Of Potatoes - 239A

# Description

Firstly i find the immediate next no. greater than y which is divisible by k, mathematically. Then i iterated over those succesive values divisible by k by incrementing by k in every iteration. At the time of printing, since we wanted x not x+y therefore we subtract y from it before printing.

# Code

```java
import java.util.*;
public class Two_Bags_Of_Potatoes {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        long y=sc.nextInt();
        long k=sc.nextInt();
        long n=sc.nextInt();
        long x=((y/k)+1)*k; //Finding the immediate next no. greater than y which is divisible by k
        if(x>n){
            System.out.println(-1);
        }
        for(long i=x;i<=n;i+=k){ //Iterating over all those succesive values divisible by k
            System.out.print((i-y)+" "); //We indeed want x not x+y therefore we subtract y from it
        }
    }
}

```

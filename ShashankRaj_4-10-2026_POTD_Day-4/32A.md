# Problem Name - Reconnaissance - 32A

# Description

I took the sliding window approach here. I initially started both pointers with index and for every iteration of i, I kept incrementing j until arr[j]-arr[i] is less than given minimum diff. Once it crosses the minimum diff, we find count of valid indices for this iteration between i and j which is given by j-i-1 and add it to the count variable. Then finally at the end , we print 2*count because (a,b) and (b,a) both are valid pairs.

# Code

```java
import java.util.*;
public class Reconnaissance {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int d=sc.nextInt();
        int arr[]=new int[n];
        int count=0;
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt;
        }
        Arrays.sort(arr);
        int j=0;
        for(int i=0;i<n-1;i++){
            while(j<n && arr[j]-arr[i]<=d){
                j++;
            }
            count+=j-i-1;
        }
        System.out.println(2*count);
    }
}

```

# Problem Name - Letter - 14A

# Description

I gone through the whole grid and found the extreme/edge points of the smallest box under which all the shaded squares are included. Then we gone from topmost row containing any shaded square to downmost one and similarly from leftmost to rightmost. In this way we printed the smallest rectangular box with all the shaded squares included.

# Code

```java
import java.util.*;
public class Letter{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        char arr[][]=new char[n][m];
        for(int i=0;i<n;i++){
            String row = sc.next();
            for(int j=0;j<m;j++){
                arr[i][j]=row.charAt(j);
            }
        }
        int up=n, down=-1, left=m, right=-1; //Initialising all the edge points 
        for(int i=0;i<n;i++){
            for(int j=0;j<m;j++){
                if(arr[i][j]=='*'){
                    up=Math.min(up,i); //Gives the topmost Row with *
                    down=Math.max(down,i); //Gives the bottommost row with *
                    left=Math.min(left, j); //Gives the leftmost column with *
                    right=Math.max(right, j); //Gives the rightmost column with *
                }
            }
        }
        for(int i=up;i<=down;i++){
            for(int j=left;j<=right;j++){
                System.out.print(arr[i][j]);
            }
            System.out.println();
        }
    }
}

```

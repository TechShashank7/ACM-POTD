# Problem Name - Tricy Sum - 558A

# Description

I first calculated the sum of all the powers of 2 and kept generating every successive power until it crossed the given n. Then i subtracted this sum twice from the total sum (from 1 to n). Twice because the powers of 2's were indeed meant to be there with -ve signs. Thus it gave us the required sum.

# Code

```java
import java.util.*;
public class TrickySum {
    public static long sum(long n){
        long sum=0;
        int i=1;
        double exp=Math.pow(2, 0);
        while(exp<=n){ //Iterating over just the powers of 2 until it crosses n
            sum+=exp;
            exp=Math.pow(2, i);
            i++;
        }
        return (n*(n+1)/2)-2*sum; //Using n(n+1)/2 to find sum till n and then subtraction the sum of the powers of 2 two times since it they were intended to be subtracted indeed as well they were with -ve signs.
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int t=sc.nextInt();
        long cases[]=new long[t];
        for(int i=0;i<t;i++){
            cases[i]=sc.nextLong();
        }
        for(int i=0;i<t;i++){
            System.out.println(sum(cases[i]));
        }
    }
}


```

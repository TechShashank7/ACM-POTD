# Problem Name - Array - 300A

# Description

I first divided the input numbers into three lists: negative numbers, positive numbers, and zeros. Keeping these categories separate makes it possible to construct groups with the required product signs. I always putted one negative number in the first group, so that group's product is negative. It then builds a positive-product second group in one of two ways:

- If there are positive numbers, it uses them for the second group. When the number of negatives is even, all positives are used there; when it is odd, the remaining negatives are included as well, and their count is even, so their product is positive.
- If there are no positive numbers, it uses two negative numbers in the second group. The product of two negatives is positive.

All numbers not assigned to the first two groups go into the third group. This includes the zeros, making the third group's product zero. The branches also leave the remaining negatives in the third group when needed. The construction relies on the input constraints providing enough negative numbers when there are no positives.


# Code

```java
import java.util.*;
public class Array{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        List<Integer> neg=new ArrayList<>();
        List<Integer> pos=new ArrayList<>();
        List<Integer> zero=new ArrayList<>();
        for(int i=0;i<n;i++){
            int a=sc.nextInt();
            if(a<0){
                neg.add(a);
            }
            else if(a>0){
                pos.add(a);
            }
            else{
                zero.add(a);
            }
        }
        if(neg.size()%2==0){ // If the amount of negative numbers is even
            System.out.println("1 "+neg.get(0)); // Adding the first -ve no. to first set
            if(pos.isEmpty()){ // If there are no +ve numbers given then we print the 2nd and 3rd -ve numbers as set 2 and the remaining -ve numbers (if any) in set 3 along with the zeros
                System.out.println("2 "+neg.get(1)+" "+neg.get(2));
                System.out.print(neg.size()-3+zero.size()+" ");
                for(int i=3;i<neg.size();i++){
                    System.out.print(neg.get(i)+" ");
                }
                for(int i=0;i<zero.size();i++){
                    System.out.print(zero.get(i)+" ");
                }    
            }
            else{ // If there are +ve numbers given then we print all of them as set 2 and the remaining -ve numbers (if any) in set 3 along with the zeros
                System.out.print(pos.size()+" ");
                for(Integer i : pos){
                    System.out.print(i+" ");
                }
                System.out.println();
                System.out.print(neg.size()-1+zero.size()+" ");
                for(int i=1;i<neg.size();i++){
                    System.out.print(neg.get(i)+" ");
                }
                for(int i=0;i<zero.size();i++){
                    System.out.print(zero.get(i)+" ");
                }
            }
        }
        else{ // If the amount of negative numbers is odd
            System.out.println("1 "+neg.get(0)); // Adding the first -ve no. to first set
            if(pos.isEmpty()){// If there are no +ve numbers given then we print the 2nd and 3rd -ve numbers as set 2 and the remaining -ve numbers (if any) in set 3 along with the zeros
                System.out.println("2 "+neg.get(1)+" "+neg.get(2));
                System.out.print(neg.size()-3+zero.size()+" ");
                for(int i=3;i<neg.size();i++){
                    System.out.print(neg.get(i)+" ");
                }
                for(int i=0;i<zero.size();i++){
                    System.out.print(zero.get(i)+" ");
                }    
            }
            else{ // If there are +ve numbers given then we print all the -ve numbers as well as the +ve numbers as set 2 and the in set 3 along with the zeros
                System.out.print(pos.size()+neg.size()-1+" ");
                for(int i=1;i<neg.size();i++){
                    System.out.print(neg.get(i)+" ");
                }
                for(Integer i : pos){
                    System.out.print(i+" ");
                }
                System.out.println();
                System.out.print(zero.size()+" ");
                for(int i=0;i<zero.size();i++){
                    System.out.print(zero.get(i)+" ");
                }
            }
        }
    }
}
```

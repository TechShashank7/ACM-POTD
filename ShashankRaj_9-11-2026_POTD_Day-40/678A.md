# Problem Name - Johny Likes Numbers  - 678A

# Description

I straightforwardly first check if the given `n` is currently already divisible by `k`. If it is, I just sum `k` to it and then print. Otherwise, I print `n + (k - n % k)` sum of n and the remaining quantity that shall be added to it to make it divisible by k.

# Code

```java
import java.util.*;
public class JohnyLikesNumbers{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        long n=sc.nextLong();
        long k=sc.nextLong();
        if(n%k==0){
            System.out.println(n+k);
        }
        else{
            System.out.println(n+(k-n%k));
        }
    }
}

```

# Problem Name - Word  - 59A

# Description

I firstly calculated the total count of uppercase and lowercase letters in the word and based on which one is more or equal, i printed the word converted to uppercase or lowercase

# Code

```java
import java.util.*;
public class Word{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        int upcount=0,lowcount=0; 
        for(int i=0;i<s.length();i++){
            if(Character.isUpperCase(s.charAt(i))){ //Tracking count of total no. of uppercase and lowercase letters in the word
                upcount++;
            }
            else{
                lowcount++;
            }
        }
        // If there are more uppercase letters than lowercase then print the word converted to uppercase and lowercase in vice-versa. Also if   both are equal then priority is given to lowercase
        if(upcount>lowcount){ 
            System.out.println(s.toUpperCase());
        }
        else{
            System.out.println(s.toLowerCase());
        }
    }
}

```

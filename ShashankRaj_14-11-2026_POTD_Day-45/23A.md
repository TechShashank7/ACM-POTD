# Problem Name - You're given a String - 23A

# Description

I started 2 nested loops i.e. i from 0 to n-1 and inner one j from i+1 to n-1. Since any duplicate substring starting at two different positions $i$ and $j$ ($i < j$) is just a common prefix of the suffixes starting at $i$ and $j$, we initialise a variable k=0 in every iteration of inner loop and start an another loop and at every iteration, i kept checking if characters at indices i+k and j+k match or not. If they do, i keep incrementing k otherwise exit this loop and start again with k=0 for next iteration of j. But before, i update the 'max' variable that's keeping track our desired maximum substring length. After all three nested loops are finished, we'll get our desired maximum substring length if any appropriate substring exists as per the requirement otherwise max stays 0 with which i initialised it.

# Code

```java
import java.util.*;
public class YouAreGivenAString {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        int n=s.length();
        int max=0;
        for(int i=0;i<n;i++){
            for(int j=i+1;j<n;j++){
                int k=0;
                while(j+k<n && s.charAt(i+k)==s.charAt(j+k)){
                    k++;
                }
                max=Math.max(max, k);
            }
        }
        System.out.println(max);
    }
}

```

# Problem Name - Anton and Danik - 734A

# Description

I created two variables, `countA` and `countB`, to store the frequency of the matches that Anton and Danik win. Based on that, I compared them and printed Anton, Danik, or friendship:
- Anton, when Anton has won more matches than Danik
- Danik, if Danik has won more matches than Anton
- Friendship, otherwise

# Code

```java
import java.util.*;
public class AntonAndDanik{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        String s=sc.next();
        int countA=0, countB=0;
        for(int i=0; i<n; i++){
            if(s.charAt(i)=='A'){
                countA++;
            }
            else{
                countB++;
            }
        }
        if(countA>countB){
            System.out.println("Anton");
        }
        else if(countA<countB){
            System.out.println("Danik");
        }
        else{
            System.out.println("Friendship");
        }
    }
}

```

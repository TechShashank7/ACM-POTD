# Problem Name - Bulbs - 615A

# Description

I added all the given bulbs into a HashSet and afterwards just checked if the number of unique bulbs i.e. the size of the set equals the number of given bulbs i.e m

# Code

```java
import java.util.*;
public class Bulbs{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        Set<Integer> set=new HashSet<>();
        int s=0;
        for(int i=0;i<n;i++){
            s=sc.nextInt();
            for(int j=0;j<s;j++){
                set.add(sc.nextInt());
            }
        }
        if(set.size()==m){
            System.out.println("YES");
        }
        else{
            System.out.println("NO");
        }
    }
}

```

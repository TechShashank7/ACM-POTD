# Problem Name - Fancy Fence  - 270A

# Description

For every given angle, I just checked if the exterior angle forming in that polygon will divide 360 completely or not. This is because the sum of all the exterior angles in any polygon is equal to 360° and we can get the number of sides in the polygon using the formula 360°/(180°-angle). If this formula gives a whole number, then the polygon will be valid, otherwise not. 

# Code

```java
import java.util.*;
public class FancyFence {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int t=sc.nextInt();
        for(int i=0;i<t;i++){
            if(360%(180-sc.nextInt())==0){
                System.out.println("YES");
            }
            else{
                System.out.println("NO");
            }
        }
    }
}

```

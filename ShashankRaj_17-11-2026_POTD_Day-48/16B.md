# Problem Name - Burglar and Matches - 16B

# Description

I firstly sorted the array in which i took input for matchboxes in a container and matches in them, based on the matches amount. Now i started a loop from end the matchboxes with most matches since we wanna maximise matches with limited matchbox carrying space, and in every iteration, i added all the matches in all the matchboxes in current container to total matches count and updated the n after filling these matchboxes. 

# Code

```java
import java.util.*;
public class BurglarMatches {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        long n=sc.nextLong();
        int m=sc.nextInt();
        long arr[][]=new long[m][2];
        for(int i=0;i<m;i++){
            arr[i][0]=sc.nextInt();
            arr[i][1]=sc.nextInt();
        }
        Arrays.sort(arr, Comparator.comparingLong(match -> match[1])); //Sorting the array containing matchboxes in each container based on the matches in a matchbox
        long matches=0;
        for(int i=m-1;i>=0 && n>0;i--){ // Starting from the matchboxes with most matches since we wanna maximise matches with limited matchbox carrying space
            long boxes=Math.min(n, arr[i][0]); 
            matches+=boxes*arr[i][1]; // Adding all the matches in all the matchboxes in this container to total matches count
            n-=boxes; // Updating the n after filling these matchboxes
        }
        System.out.println(matches);
    }
}

```

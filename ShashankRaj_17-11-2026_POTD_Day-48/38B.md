# Problem Name - Chess - 38B

# Description

I checked over all the 8 × 8 = 64 squares. Firstly, I checked a condition so that we don't place our knight on any square already occupied by a rook and an old knight. Then I check that we don't place our knight in a row or column in which the rook is residing, because it could attack our knight. Now, while placing our knight, we also have to see that our knight doesn't attack the rook and the old knight. Now, as we already know, a knight moves either two steps vertically and one step horizontally, or vice versa. Hence, we can say that |r1-r2|*|c1-c2|=2 , where (r1,c1) is the initial position of the knight and (r2,c2) is the final position of the knight. 

# Code

```java
import java.util.*;
public class Chess {
    public static void main(String[] args) {
        Scanner sc=new Scanner(System.in);
        String rook=sc.next();
        String knight=sc.next();
        int r1=rook.charAt(1)-'1';
        int c1=rook.charAt(0)-'a';
        int r2=knight.charAt(1)-'1';
        int c2=knight.charAt(0)-'a';
        int ways=0;
        for(int r=0;r<8;r++){
            for(int c=0;c<8;c++){
                if((r==r1 && c==c1) || (r==r2 && c==c2)){ // Can't place on squares already occupied by a rook or knight. 
                    continue;
                }
                if(r==r1 || c==c1){ // Can't place in the row and column in which the rook is placed
                    continue;
                }
                if(Math.abs(r-r1)*Math.abs(c-c1)==2){ // The placed knight shall not be attacking the rook. 
                    continue;
                }
                if(Math.abs(r-r2)*Math.abs(c-c2)==2){ // The placed knight shall not be attacking the old knight. 
                    continue;
                }
                ways++;
            }
        }
        System.out.println(ways);
    }
}

```

# Problem Name - Beautiful Year - 271A

# Description

I started a loop from the next number after the given year and kept checking if all the digits of it are distinct. If they are, we print it and stop the loop. 

# Code

```java
import java.util.*;
public class BeautifulYear {
    public static void main(String[] args) {
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        while(true){
            n++;
            int a=(n/1000); //First digit 
            int b=(n/100)%10; //Second digit 
            int c=(n/10)%10; //Third digit 
            int d=n%10; //Fourth digit 
            if (a != b && a != c && a != d && b != c && b != d && c != d){ //Checking if all digits are distinct 
                System.out.println(n);
                return;
            }
        }
    }
}

```

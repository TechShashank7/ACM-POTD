# Problem Name - Queries about less or equal elements - 600B

# Description

First, we sort the first array So that we didn't need to iterate over the whole first array in order to find the number of elements less than every element in the second array. Therefore, we start a loop and iterate over all the elements in Second array. For every element, we call our custom binary Search  function and pass the first array to it, which returns the index inside the first array before which all the elements are less than that element of the second array. 

# Code

```java
import java.util.*;
public class Queries_about_less_than_or_equal_Elements {
    public static int BinarySearch(int arr[], int k){ //Our custom binary search function that will return the maximum index before which all the elements less than k are present 
        int low=0,high=arr.length;
        while(low<high){
            int mid=low+(high-low)/2;
            if(arr[mid]<=k){
                low=mid+1;
            }
            else{
                high=mid;
            }
        }
        return low;
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        int arr1[]=new int[n];
        int arr2[]=new int[m];
        for(int i=0;i<n;i++){
            arr1[i]=sc.nextInt();
        }
        for(int i=0;i<m;i++){
            arr2[i]=sc.nextInt();
        }
        Arrays.sort(arr1); //Sorting arr1 so that we didn't need to iterate over the whole arr1 in order to find the required number of elements less than K 
        for(int i=0;i<m;i++){
            System.out.print(BinarySearch(arr1, arr2[i])+" "); //For every element in arr2, we check arr1 to find the index before which all the elements are less than arr2[i]. 
        }
    }
}

```

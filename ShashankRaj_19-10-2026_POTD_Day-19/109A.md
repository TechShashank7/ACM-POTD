# Problem Name - Lucky Sum of Digits - 109A

# Description

For mimimum no. satisfying, it should have maximum of 4's and minimum of 7's i.e. 4x+7y=n. I started a loop with `x = 0`, and at every iteration I kept checking if `n - 4x` is divisible by 7. If it is, then I just print `x * 4` and `y * 7`. If `4x` becomes greater than `n`, then no such combination exists, and we print -1. 

# Code

```java
import java.util.*;
public class LuckySumOfDigits {
    public static void main(String[] srgs){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        for(int x=0;4*x<=n;x++){
            if((n-4*x)%7==0){
                for(int i=1;i<=x;i++){
                    System.out.print("4");
                }
                for(int i=1;i<=(n-4*x)/7;i++){
                    System.out.print("7");
                }
                return;
            }
        }
        System.out.println("-1");
    }
}

```

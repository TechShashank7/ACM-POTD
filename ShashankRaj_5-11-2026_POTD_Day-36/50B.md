# Problem Name - Choosing Symbol Pairs - 50B

# Description

I first created a frequency hash map and stored the frequency of all the letters in it. Then, for every letter appearing $C$ times in the string, we can form $C \times C$ valid pairs using just that letter. And I have summed up this for all the letters

# Code

```java
import java.util.*;
public class ChoosingSymbolPairs{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        Map<Character, Integer> map=new HashMap<>();
        for(int i=0;i<s.length();i++){ // Storing the frequency of all the characters 
            map.put(s.charAt(i), map.getOrDefault(s.charAt(i), 0)+1);
        }
        long ans=0;
        for(Character i : map.keySet()){
            long f=map.get(i);
            ans+=f*f; // if a letter appears $C$ times in the string, we can form $C \times C$ valid pairs using just that letter. And we have summed up this for all the letters
        }
        System.out.println(ans);
    }
}

```

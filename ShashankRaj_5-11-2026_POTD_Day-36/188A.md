# Problem Name - Hexagonal Numbers - 188A

# Description

 I first read the integer input $n$ into the first memory cell ([0]) and squaring it to store $n^2$ in the second cell ([1]). Next, i multiplied that second cell by 2 to yield $2n^2$. Finally, i subtracted the original input $n$ from the second cell to get $2n^2 - n$ and printed the final result to the console.

# Code

```roco
iin [0]
mul [1] [0] [0]
mul [1] [1] 2
sub [1] [1] [0]
iout [1]
ac

```

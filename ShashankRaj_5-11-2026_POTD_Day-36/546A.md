# Problem Name - Soldier and Bananas - 546A

# Description

Since the soldier needs w bananas and cost of banana rises in an arithmetic progression (1.k+2.k+3.k.... => k(1+2+3+....)), i calculated the total cost of the bananas the soldier required as k(w(w+1)/2). Afterwards, I check if this amount is greater than the amount of money he has i.e. n. Then I subtract n from this. Otherwise, I print 0 if he doesn't need to borrow any money. 

# Code

```java
import java.util.*;
public class SoldierAndBananas {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        long k=sc.nextInt();
        long n=sc.nextInt();
        long w=sc.nextInt();
        System.out.println((w*(w+1)/2)*k>n ? (w*(w+1)/2)*k-n : 0);
    }
}

```

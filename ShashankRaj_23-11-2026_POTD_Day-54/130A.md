# Problem Name - Hexagonal Numbers  - 130A

# Description

I first read the integer $n$ onto the stack (&) and duplicated it (:) so two copies are available. I then multiplied the top copy by 2 and subtracts 1 (2*1-) to compute $2n - 1$, then multiplied that result by the remaining $n$ (*) to get $n(2n - 1)$. Finally, . pops and prints the hexagonal number, and @ terminates the program.

# Code

```befunge
&:2*1-*.@
```

# Problem Name - Extra-terrestial Intelligence - 36A

# Description

I first stored teh indices of all the 1's occurences in an array arr and then i calculated the diffrence between arr[1] and arr[0]. Then i looped over arr to check if the diffrence between other consecutive indices is also equal to diffrence between arr[1] and arr[0]. If the confition not satisfies even once, i printed NO and exited the code. Otehrwise if loop finishes succesfully, i printed YES since all the intervals between successive signals are equal

# Code

```java
import java.io.*;
import java.util.*;

public class ExtraTerrestialIntelligence {
    public static void main(String[] args) throws Exception {
        try (Scanner sc = new Scanner(new File("input.txt"));
             PrintWriter out = new PrintWriter("output.txt")) {

            int n = sc.nextInt();
            String s = sc.next();
            int[] arr = new int[n];
            int j = 0;

            for (int i = 0; i < n; i++) { //Storing indices of all 1's
                if (s.charAt(i) == '1') {
                    arr[j++] = i;
                }
            }

            for (int i = 2; i < j; i++) {
                if (arr[i] - arr[i - 1] != arr[1] - arr[0]) { //Gap between any two consecutive indices shall be same in order for teh signal to be an extra-terrestial intelligence otherwise not
                    out.println("NO");
                    return;
                }
            }
            out.println("YES");
        }
    }
}

```

# Problem Name - Center Alignment - 5B

# Description

I first readed every input line and found the length of the longest line. This length determines the width of the text area inside the frame. It then builds the entire output in a `StringBuilder` to avoid printing each character separately.
For each line, the difference between its length and the maximum length gives the total number of padding spaces needed. If that difference is even, the spaces are split equally on both sides. If it is odd, one side must have one extra space. The `align` counter alternates which side receives that extra space, keeping the text centered across the frame. The counter changes only for lines with an odd padding difference.
Finally, i added a border of asterisks above and below the lines, and an asterisk at the start and end of each line. I then printed the completed result once.

# Code

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.ArrayList;
import java.util.List;

public class CenterAlignment {
    public static void main(String[] args) throws IOException {
        BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));
        List<String> lines=new ArrayList<>();
        int maxLen=0;
        String line;
        while((line = reader.readLine()) != null){
            lines.add(line);
            maxLen=Math.max(maxLen, line.length());
        }

        StringBuilder output = new StringBuilder();
        int align=0;
        appendRepeated(output, '*', maxLen + 2);
        output.append('\n');

        for(int i=0;i<lines.size();i++){
            String currentLine = lines.get(i);
            int padding = maxLen - currentLine.length();
            output.append('*');
            if((currentLine.length()%2==0 && maxLen%2==0) || (currentLine.length()%2!=0 && maxLen%2!=0)){ // Both current line's length and maxLen is either odd or even
                appendRepeated(output, ' ', padding / 2);
                output.append(currentLine);
                appendRepeated(output, ' ', padding / 2);
            }
            else{ // Either of maxLen or current line's length is even or odd
                if(align%2==0){ // Rounding distance to left edge
                    appendRepeated(output, ' ', padding / 2);
                    output.append(currentLine);
                    appendRepeated(output, ' ', padding / 2 + 1);
                }
                else{ // Rounding distance to right edge
                    appendRepeated(output, ' ', padding / 2 + 1);
                    output.append(currentLine);
                    appendRepeated(output, ' ', padding / 2);
                }
                align++;
            }
            output.append('*').append('\n');
        }
        appendRepeated(output, '*', maxLen + 2);
        System.out.print(output);
    }

    private static void appendRepeated(StringBuilder output, char character, int count) {
        for(int i=0;i<count;i++){
            output.append(character);
        }
    }
}
```

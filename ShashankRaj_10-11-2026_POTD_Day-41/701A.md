# Problem Name - Cards - 701A

# Description

I initialized a 2D array and stored the elements with respect to their given indices incremented by 1  in that array. Then I sorted the array based on the elements in ascending order and started a loop to run n/2 times, printing the pairs in a manner : starting one and last one , and kept moving inwards into the array with every iteration. 

# Code

```java
import java.util.*;
public class Cards {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int pairs[][]=new int[n][2];
        for(int i=0;i<n;i++){
            pairs[i][0]=sc.nextInt();
            pairs[i][1]=i+1;
        }
        Arrays.sort(pairs, Comparator.comparingInt(p -> p[0]));
        for(int i=1;i<=n/2;i++){
            System.out.println(pairs[i-1][1]+" "+pairs[n-i][1]);
        }
    }
}

```

# Problem Name - Double Cola - 82A

# Description

I initialized a loop and kept iterating over it, subtracting current block size from given n and doubling the block size, until the given `n` falls under the current block size. Then I printed the person at the position of the last index of the current block size. 

# Code

```java
import java.util.*;
public class DoubleCola {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        long n=sc.nextLong();
        String arr[]={"Sheldon", "Leonard", "Penny", "Rajesh", "Howard"};
        long block=1;
        while(5*block<n){ //Skip complete blocks while n is beyond the current block
            n-=5*block; //Remove the whole block
            block*=2; //Next block has twice as many copies per person
        }
        System.out.println(arr[(int)((n-1)/block)]);
    }
}

```

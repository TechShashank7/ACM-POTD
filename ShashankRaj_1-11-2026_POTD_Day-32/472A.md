# Problem Name - Design Tutorial: Learn from Math - 472A

# Description

I checked if the number is even or odd. For even, I printed the two numbers as 4, the first composite number, and the other one, n - 4. Since the problem guarantees $n \ge 12$, $n - 4 \ge 8$, meaning it is guaranteed to be composite. For odd, I printed the first number as 9, the first odd composite number, and n - 9. Since $n \ge 12$, $n - 9 \ge 3$, which means $n - 9$ is an even number strictly greater than 2, making it composite.

# Code

```java
import java.util.*;
public class DesignTutorial_LearnFromMath{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        if(n%2==0){
            System.out.println("4 "+(n-4));
        }
        else{
            System.out.println("9 "+(n-9));
        }
    }
}

```

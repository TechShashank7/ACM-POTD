# Problem Name - Yaroslav and Permutations - 114B

# Description

I first created a frequency hashmap to store the count of all the numbers and then found out the number with most frequency. Then i just checked if this count<=(n+1)/2. This is because for the element with most frequency, let it be f, there shall be f-1 spaces between them to satisfy the required condition This means that remaining elements i.e. n-f>=f-1 => f<=(n+1)/2

# Code

```java
import java.util.*;
public class YaroslavAndPermutations {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int arr[]=new int[n];
        Map<Integer, Integer> map=new HashMap<>();
        for(int i=0;i<n;i++){ // Creating a requency hashmap to store the count of all the numbers
            arr[i]=sc.nextInt();
            map.put(arr[i], map.getOrDefault(arr[i], 0)+1);
        }
        int max=Integer.MIN_VALUE; 
        for(Integer i : map.keySet()){ // Finding the element with most appearances in the array
            max=Math.max(max, map.get(i));
        }
        if(max<=(n+1)/2){
            System.out.println("YES");
        }
        else{
            System.out.println("NO");
        }
    }
}

```

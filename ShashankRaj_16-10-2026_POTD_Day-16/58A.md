# Problem Name - Chat Room - 58A

# Description

I iterated over the given string and maintaning a variable "match", kept incrementing it as we keep finding the characters of "hello" string in a contiguous order.

# Code

```java
import java.util.*;
public class ChatRoom {
    public static void main(String[] args) {
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        int match=0;
        for(char i : s.toCharArray()){
            if(match<5 && i=="hello".charAt(match)){
                match++;
            }
        }
        System.out.println(match==5 ? "YES" : "NO");
    }
}

```

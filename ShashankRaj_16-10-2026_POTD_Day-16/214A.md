# Problem Name - System of Equations   - 214A

# Description

Since a and b will always be less than or equal to the minimum of n and m, I initialized a with 0 and iterated all the way till the minimum of n and m. For every value of a, I found the corresponding value of b based on the first equation. Then I checked two conditions: whether b is positive and it satisfies the second equation or not. If it satisfies both equations, we consider this solution as valid and increment the count variable, which is tracking the number of valid solutions. At last, we print it. 

# Code

```java
import java.util.*;
public class SystemOfEquations{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        int count=0;
        for(int a=0;a<=Math.min(n, m);a++){  //a and b will always be less than or equal to minimum of n and m.
            int b=n-a*a;
            if((b>0 || b==0) && a+b*b==m){ //For every value of `a`, we are checking the corresponding `b`, and if it matches these two conditions, then we are storing that solution as valid. 
                count++;
            }
        }
        System.out.println(count);
    }
}

```

# Problem Name - Hexadecimal Numbers - 9C

# Description

I used depth-first recursion to generate only the valid numbers composed of 0s and 1s. Starting from 1, each recursive call counts the current number and branches out by appending a 0 (curr * 10) and a 1 (curr * 10 + 1) to build the next candidates. Any branch where the generated value exceeds $n$ immediately stops and returns 0.

# Code

```java
import java.util.*;
public class HexadecimalsNumbers {
    static long n;
    static int countValid(long curr) {
        if (curr > n) return 0;
        return 1 + countValid(curr * 10) + countValid(curr * 10 + 1);
    }
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        n=sc.nextLong();
        System.out.println(countValid(1));
    }
}

```

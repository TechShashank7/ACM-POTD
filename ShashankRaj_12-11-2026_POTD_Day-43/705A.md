# Problem Name - Hulk - 705A

# Description

I created an empty stringbuilder "str" first and initialised a variable "that" to keep the count of inserting the word "that" between the phrases "I hate" and "I love". And then started an loop from i = 1 to n and in every iteration, i checked if i is odd or even. If i is odd then i appended "I hate " to str otherwise "I love ". Also in the same iteration i checked if current count of "that" is greater than 0 and if it is then i append an "that" to str and decrement the count of that by 1. At the end of loop, i appended "it" to str to complete and print the required sentence i.e. feelings of Dr. Bruce Banner.

# Code

```java
import java.util.*;
public class Hulk{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        StringBuilder str=new StringBuilder();
        int that=n-1;
        for(int i=1;i<=n;i++){
            if(i%2!=0){
                str.append("I hate ");
            }
            else{
                str.append("I love ");
            }
            if(that!=0){
                str.append("that ");
                that--;
            }
        }
        str.append("it");
        System.out.println(str);
    }
}

```

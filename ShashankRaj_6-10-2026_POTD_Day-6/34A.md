# Problem Name - Reconnaissance - 34A

# Description

I started checking the diff between an element with its successive element in the circular array and where the minimum diff occured, i saved that index and printed it and the successive index.

# Code

```java
import java.util.*;
public class Reconnaissance2 {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int arr[]=new int[n];
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
        }
        int min=Integer.MAX_VALUE;
        int index=0;
        for(int i=0;i<n;i++){
            if(Math.abs(arr[i]-arr[(i+1)%n])<min){ //Finding the index where minimum difference occurs with succesive element
                min=Math.abs(arr[i]-arr[(i+1)%n]);
                index=i;
            }
        }
        System.out.println(index+1+" "+((index+1)%n+1));
    }
}

```

# Problem Name - Quasi-palindrome - 863A

# Description

I firstly got the no. rid of any trailing zeros by dividing the no. by 10 until remainder is 0, so that we can directly do the palindrome check on it. Then according to the palindrome check we did afterwards, we printed YES and NO accordingly.

# Code

```java
import java.util.*;
public class QuasiPalindrome {
    public static void main(String[] args) {
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        if(n==0){
            System.out.println("YES"); 
        }
        while(n%10==0){ //Removing any trailing zeros
            n/=10;
        }
        if(Integer.toString(n).equals(new StringBuilder(Integer.toString(n)).reverse().toString())){ //Checking if this no. we got after removing the trailing zeros is a palindrome or not
            System.out.println("YES");
            return;
        }
        System.out.println("NO");
    }
}

```

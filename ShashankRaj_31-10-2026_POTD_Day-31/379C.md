# Problem Name - New Year Ratings Change - 379C

# Description

I maintained all the given ratings in an array `arr`. Also, I maintained an array `idx` that stores indices and sorted it based on the comparison between the ratings in array `arr`. Also I created an array `ans` to store the smallest possible unique rating in it that's favorable to both the users and the site X. Afterwards, for every index in array `idx`, I check if the rating in array `ans` is actually greater than the one stored in the variable `last` (that's keeping track of the last rating we have visited). If it's greater than the rating stored in `last`, then insert it at this index in the `ans` array. Otherwise, increment `last` by 1 and insert it at this index in `ans`. Afterwards, I updated the variable `last` with `ans[i]`. 

# Code

```java
import java.util.*;

public class NewYearRatingsChange {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        long[] arr = new long[n];
        Integer idx[]=new Integer[n];
        long ans[]=new long[n];

        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextLong();
            idx[i] = i;
        }

        Arrays.sort(idx, (i, j) -> Long.compare(arr[i], arr[j])); //Sorting the indices based on the comparisons between the ratings 
        long last = 0;

        for (int i : idx) {
            ans[i] = Math.max(arr[i], last + 1); //If the current rating is greater than the one at the last index, then keep it. Otherwise, replace it with the last after doing an increment to it. 
            last = ans[i]; //Bring last to this current rating. 
        }
        StringBuilder output = new StringBuilder();
        for (long x : ans) {
            output.append(x).append(" ");
        }
        System.out.print(output);
    }
}

```

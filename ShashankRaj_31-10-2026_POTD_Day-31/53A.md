# Problem Name - Autocomplete - 53A

# Description

For every given visited page, I checked if its name starts with the given input part, and I print the one of them which is the smallest lexicographically. If none of the given visited pages starts with the given input part, then I print the given input part indeed. 

# Code

```java
import java.util.*;
public class Autocomplete {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        int n=sc.nextInt();
        String ans=null;
        for(int i=0;i<n;i++){
            String a=sc.next();
            if(a.startsWith(s)){
                if(ans==null || a.compareTo(ans)<0){
                    ans=a;
                }
            }
        }
        System.out.println(ans==null ? s : ans);
    }
}

```

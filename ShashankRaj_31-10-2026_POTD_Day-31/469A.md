# Problem Name - I Wanna Be the Guy - 469A

# Description

I maintained two sets and added all the levels passed by Little X and Little Y to them. Then I checked whether all the levels of the game are passed either by Little X or by Little Y. If there is a level that can't be passed by any of them, then I printed "Oh, my keyboard!". Otherwise, "I become the guy".

# Code

```java
import  java.util.*;
public class IWannaBeTheGuy {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int p=sc.nextInt();
        Set<Integer> X=new HashSet<>();
        for(int i=0;i<p;i++){
            X.add(sc.nextInt());
        }
        int q=sc.nextInt();
        Set<Integer> Y=new HashSet<>();
        for(int i=0;i<q;i++){
            Y.add(sc.nextInt());
        }
        for(int i=1;i<=n;i++){
            if(!(X.contains(i) || Y.contains(i))){ // Neither little X nor little Y can pass this level. 
                System.out.println("Oh, my keyboard!");
                return;
            }
        }
        System.out.println("I become the guy.");
    }
}

```

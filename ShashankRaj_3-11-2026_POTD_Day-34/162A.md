# Problem Name - Pentagonal Numbers - 162A

# Description

I used Factor's stack-based postfix system to evaluate the formula $(3n^2 - n) / 2$ sequentially. It reads the input integer and duplicates it on the stack so both the $n^2$ term and the subtracted $n$ are readily available. The math operations then square the number, multiply by 3, and subtract the original $n$ by swapping their stack positions. Finally, it applies integer division by 2 and uses the dot (`.`) command to output the result. 

# Code

```factor
USING: io kernel math math.parser prettyprint ;

readln string>number
dup dup * 3 * swap - 2 /i
.
```

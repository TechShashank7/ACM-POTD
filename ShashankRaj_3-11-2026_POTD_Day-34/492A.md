# Problem Name - Vanya and Cubes - 492A

# Description

I started a loop, and in every iteration I kept subtracting the number of cubes required to make the current layer from the overall remaining cubes (by using the formula n × (n + 1) / 2). If, in any iteration, the number of remaining cubes becomes zero or less than zero, then we can't form any more layers. The current height that we kept incrementing in every iteration after making a layer is our final answer.  

# Code

```java
import java.util.*;
public class VanyaAndCubes{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int height=0;
        int i=1;
        while(true){
            n-=(i*(i+1))/2; // Subtracting the number of cubes we get to make this layer from the remaining number of cubes 
            if(n>=0){ // Till we have any amount of cubes left, we kept incrementing the height after every subtraction
                i++;
                height++;
            }
            else{ // If there are no cubes left, then the current height is our answer. 
                break;
            }
        }
        System.out.println(height);
    }
}

```

# Problem Name - Bargaining Table - 22B

# Description

I confined my current search for possible rectangles by defining a window using pointers `top` and `bottom`. I started a loop by confining the pointer `top` and initialized a boolean array called `valid`, in which I was storing `false` for the columns containing `1` in the current iteration and `true` for those that don't contain `1`. Initially, I started by filling the whole array with `true`. For the current iteration, I kept iterating in it and kept increasing the current width until I found any `1` at any position. I also kept updating the variable `max width`, which Was keeping track of the maximum width till now. Suppose we found a 1, then we reset the current width to 0 and start over. Once this finishes up, we update the current height using `bottom - top + 1` and also update our perimeter of this rectangle if the max width is greater than 0. At last, we print the maximum perimeter of the rectangle that we found so far in the whole process. 

# Code

```java
import java.util.*;
public class BargainingTable {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        int arr[][]=new int[n][m];
        for(int i=0;i<n;i++){
            String s=sc.next();
            for(int j=0;j<m;j++){
                arr[i][j]=s.charAt(j)-'0';
            }
        }
        int ans=0;
        for(int top=0;top<n;top++){
            boolean valid[]=new boolean[m]; // Array in which you will store `false` for the columns containing `1` in the current iteration and `true` in those that don't contain any `1` 
            Arrays.fill(valid, true); // Starting with all columns is true. 
            for(int bottom=top;bottom<n;bottom++){
                for(int j=0;j<m;j++){
                    if(arr[bottom][j]==1){
                        valid[j]=false;
                    }
                }
                int width=0, maxWidth=0;
                for(int j=0;j<m;j++){ // Iterating over the current window and incrementing the current width until we find any 1, and updating the max width in every iteration
                    if(valid[j]){
                        width++;
                        maxWidth=Math.max(maxWidth, width);
                    }
                    else{ // If we found a 1, then reset current width and start with 0. 
                        width=0;
                    }
                }
                int height=bottom-top+1; // Current height of the window as calculated between the current positions of the top and bottom pointers 
                if(maxWidth>0){ // Update the current perimeter of the rectangle if the max width has updated. 
                    ans=Math.max(ans, 2*(maxWidth+height));
                }
            }
        }
        System.out.println(ans);
    }
}

```

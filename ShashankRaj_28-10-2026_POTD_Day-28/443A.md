# Problem Name - Anton and Letters - 443A

# Description

I used the simplest approach here. I just added all the alphabets from the given string to a set to remove all the duplicates, and then I printed the size of the set, which is the required answer. 

# Code

```java
import java.util.*;
public class AntonAndLetters{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.nextLine();
        Set<Character> set=new HashSet<>();
        for(char c : s.toCharArray()){
            if (c>='a' && c<='z') {
                set.add(c);
            }
        }
        System.out.println(set.size());
    }
}

```

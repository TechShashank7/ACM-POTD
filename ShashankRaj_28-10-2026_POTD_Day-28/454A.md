# Problem Name - Little Pony and Crystal Mine - 454A

# Description

I calculated the middle of every row first. Then i place the no. of stars equal to absolute diff of mid and index of that row (which we are starting with 0 and going till n-1), at both leftmost and rightmost ends of the row, and the remaining no. of postions in the middle of row to be filled by diamonds.

# Code

```java
import java.util.*;
public class LittlePonyAndCrystalMine{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int mid=n/2;
        
        for(int i=0; i<n; i++) {
            int dist=Math.abs(mid-i);
            int stars=dist;
            int diamonds=n-(2*dist);
            
            System.out.println("*".repeat(stars)+"D".repeat(diamonds)+"*".repeat(stars));
        }
    }
}

```

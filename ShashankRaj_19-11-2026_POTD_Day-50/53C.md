# Problem Name - Little Frog - 53C

# Description

I used 2-pointer approach and used two pointers, left and right starting at extreme ends i.e. left=1 and right=n-1. Then i started a loop until left<=right and in every iteration i kept printing left and incremented by 1 and for right, i again checked if left<=right and if then i printed right too and decremented it. In this wa, i started with the jump form one extreme end to other and then kept iterating inwards.

# Code

```java
import java.util.*;
public class LittleFrog{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int left=1, right=n;
        StringBuilder s=new StringBuilder();
        while(left<=right){
            s.append(left).append(" ");
            left++;
            if(left<=right){
                s.append(right).append(" ");
                right--;
            }
        }
        System.out.println(s.toString());
    }
}

```

# Problem Name - Flag - 16A

# Description

For every square in a row, I check if it's equal to the first square of the row or not. And for every column, I check if it's equal to its adjacent one or not. If it fails any of these tests, then it prints "NO" right away. Otherwise, "YES". 

# Code

```java
import java.util.*;
public class Flag {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        int flag[][]=new int[n][m];
        for(int i=0;i<n;i++){
            String s=sc.next();
            for(int j=0;j<m;j++){
                flag[i][j]=s.charAt(j);
            }
        }
        for(int i=0;i<n;i++){
            for(int j=1;j<m;j++){
                if(flag[i][j]!=flag[i][0]){ //Checking adjacent squares in a row 
                    System.out.println("NO");
                    return;
                }
            }
            if(i<n-1){
                if(Arrays.equals(flag[i+1], flag[i])){ //Checking adjacent columns 
                    System.out.println("NO");
                    return;
                }
            }
        }
        System.out.println("YES");
    }
}


```

# Problem Name - Wet Shark and Odd and Even - 621A

# Description

My approach is pretty straightforward here. I'm calculating the sum of all the given numbers first. If its already even then i print it directly otherwise for making it even plus making sure that it stays largest sum, can be done by subtracting smallest odd number from the given ones and then printing it.

# Code

```java
import java.util.*;
public class WetShark_and_Odd_and_Even {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        long arr[]=new long[n];
        long sum=0;
        long min=Integer.MAX_VALUE;
        for(int i=0;i<n;i++){
            arr[i]=sc.nextLong();
            sum+=arr[i];
            if(arr[i]%2!=0){
                min=Math.min(min, arr[i]);
            }
        }
        if(sum%2!=0){
            System.out.println(sum-min); //If the sum is odd then subtracting the smallest odd no. from it will give us the largest even sum
            return;
        }
        System.out.println(sum); //Otherwise we print the even sum directly
    }
}


```

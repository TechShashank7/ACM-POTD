# Problem Name - Second Order Statistics - 22A

# Description

I first added all the elements in a TreeSet to get rid of duplicates as well as have them in sorted order. Then i removed the mimimum element from the given elements, from the set and afterwards printed the first element of set now which is the mimimum now and our required second minimum. Additionally i am checking after removing the first element whether the set gets empty and if it does then i am printing NO and returning since this means that there is no second mimimum to exist.

# Code

```java
import java.util.*;
public class SecondOrderStatistics {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        Set<Integer> set = new TreeSet<>();
        int min=Integer.MAX_VALUE;
        for(int i=0;i<n;i++){
            int x=sc.nextInt();
            set.add(x);
            min=Math.min(min, x);
        }
        set.remove(min);
        if(set.isEmpty()){ //If set gets empty after removing the min then there was indeed just one element in it and so second min doesn't exists
            System.out.println("NO");
            return;
        }
        for(int i : set){ 
            System.out.println(i); //First element of the set now is the second min we need since actual min was already removed
            return;
        }
    }
}

```

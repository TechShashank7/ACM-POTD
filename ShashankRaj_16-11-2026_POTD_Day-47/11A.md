# Problem Name - Increasing Sequence - 11A

# Description

I ran a loop from `i = 1` to `n`, and in every iteration I checked if the current element is less than or equal to the preceding element. If it is, then I calculated the total moves required to make it greater than the preceding element, by dividing the difference of both by d and adding 1 to it (let's say it be equal to curr). Then I added this to the total moves counter and also updated the current element by adding the product of `d` and `curr`. 

# Code

```java
import java.util.*;
public class IncreasingSequence{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int d=sc.nextInt();
        int arr[]=new int[n];
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
        }
        int moves=0; // Total no. of moves
        for(int i=1;i<n;i++){
            if(arr[i]<=arr[i-1]){
                int curr=(arr[i-1]-arr[i])/d+1; // The total moves needed to make arr[i]>arr[i-1]
                moves+=curr; //Updating the total moves counter 
                arr[i]+=d*curr; //Updating arr[i]
            }
        }
        System.out.println(moves);
    }
}

```

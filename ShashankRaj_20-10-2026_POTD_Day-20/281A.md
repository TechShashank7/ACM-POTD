# Problem Name - Word Capitalization - 281A

# Description

I gone with the most straightforward approach as possible. I just converted the first letter of word to alphabet and printed it followed by the rest of the letters as usual.

# Code

```java
import java.util.*;
public class WordCapitalization{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        System.out.println(s.substring(0, 1).toUpperCase()+s.substring(1, s.length()));
    }
}

```

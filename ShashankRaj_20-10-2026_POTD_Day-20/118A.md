# Problem Name - String Task - 118A

# Description

I firstly created an array list of vowels, and then for every letter in the given word, I check if it's in that array list. If it is, then I skip it. Otherwise, I print it with a dot in front of it. 

# Code

```java
import java.util.*;
public class StringTask{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next().toLowerCase();
        List<String> chars = new ArrayList<>(Arrays.asList(s.split("")));
        List<String> vowels = new ArrayList<>(Arrays.asList("a", "e", "i", "o", "u", "y"));
        for(String i : chars){ //If the letter is in the vowels array list, then skip it. Otherwise, print it with a dot in front of it. 
            if(!vowels.contains(i)){
                System.out.print("."+i);
            }
        }
    }
}

```

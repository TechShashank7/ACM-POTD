# Problem Name - Regular Bracket Sequence - 26B

# Description

I started a loop, and at every iteration I checked if the current character is an open bracket or a close bracket. If it's an open bracket, then I increment its count by 1. If it's a close bracket, then I first check if the count of open brackets is greater than 1, and then decrement it and increase the count of bracket pairs by 1. 

# Code

```java
import java.util.*;
public class RegularBracketSequence {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String s=sc.next();
        int open=0, count=0;
        for(int i=0;i<s.length();i++){
            if(s.charAt(i)=='('){
                open++; //Incrementing the count of open brackets 
            }
            else{ //If we find a close bracket, then we check if the number of open brackets we have counted till now is greater than zero. If it is, then we decrement it and increase the pair count by one. 
                if(open>0){
                    open--;
                    count++;
                }
            }
        }
        System.out.println(count*2); 
    }
}


```

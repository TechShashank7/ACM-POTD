# Problem Name - Theatre Square  - 1A

# Description

I firstly checked a against n if its completely divisible or not. If its copletely divisible along edge n then i multiplied the ans variable via which we are keeping track of the total no. of tiles to n/a and if not then i multiply with (n/a+1) since the tile shoudl stay off the edge even if it goes out of the boundary. Similarly for m edge. And then the final ans is the product of both.

# Code

```java
import java.util.*;
public class TheatreSquare{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        int a=sc.nextInt();
        long ans=1;
        if(n%a==0){
            ans*=n/a;
        }
        else{
            ans*=n/a+1;
        }
        if(m%a==0){
            ans*=m/a;
        }
        else{
            ans*=m/a+1;
        }
        System.out.println(ans);
    }
}

```

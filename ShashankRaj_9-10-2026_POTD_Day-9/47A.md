# Problem Name - Triangular Numbers  - 47A

# Description

I ran a loop starting with 1 and then kept incrementing with next trangular no. in sequence using n(n+1)/2. If n matches any of the i, i.e. triangular no., then it's a triangular number, and we print "YES". Once i gets greater than n, then it means that there is no triangular number which matches with n, and therefore we didn't need to check further and print "NO".

# Code

```java
import java.util.*;
public class TriangularNumbers{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        long n=sc.nextInt();
        long j=1;
        for(long i=1;;i=j*(j+1)/2){ //Starting with 1 and incrementing with subsequent triangular number steps
            if(n==i){  //if n gets equal to any triangular no. then printing YES
                System.out.println("YES");
                break;
            }
            if(i>n){ //Once i crosses n therefore n is not a triangular no. so we didnt need to check further
                System.out.println("NO");
                break;
            }
            j++;
        }
    }
}

```

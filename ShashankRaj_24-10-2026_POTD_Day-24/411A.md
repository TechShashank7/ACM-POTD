# Problem Name - Password Checker - 411A

# Description

I perfomed all 4 checks and if the give string doesnt satisfies either of them then i print "Too weak" otherwise "Correct"

# Code

```java
import java.util.*;
public class PasswordChecker{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String pwd=sc.next();
        if(pwd.length()<5){ 
            System.out.println("Too weak");
            return;
        }
        boolean caps=false;
        boolean small=false;
        boolean digit=false;
        for(char i : pwd.toCharArray()){
            if((i>=65 && i<=90)){
                caps=true;
            }
            if(i>=97 && i<=122){
                small=true;
            }
            if(i>=48 && i<=57){
                digit=true;
            }
        }
        if(!caps || !small || !digit){
            System.out.println("Too weak");
            return;
        }
        System.out.println("Correct");
    }
}

```

# Problem Name - Ciel and Dancing - 322A

# Description

I took 1st boy as a pivot and made him dance with all the m girls first . Then i took girl 1 as a pivot and made her dance with all remaining i.e. n-1 boys. This gives us total m+n-1 dance performances

# Code

```java
import java.util.*;
public class CielAndDancing {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        System.out.println(n+m-1);
        for(int i=1;i<=m;i++){ //Taking 1st boy as a pivot and making him dance with all m girls
            System.out.println(1+" "+i);
        }
        for(int i=2;i<=n;i++){ //Taking girl 1 as a pivot and making her dance with all the boys except the first one who had already danced with all girls before
            System.out.println(i+" "+1);
        }
    }
}

```

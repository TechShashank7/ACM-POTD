# Problem Name - Sale - 34B

# Description

One thing is sure: we have to just consider the TV with negative prices because that's where Bob will make money. therefore : 

1. I sorted the given array so that the TVs with negative prices come first.
2. I ran a loop, and in every iteration, I checked if the price of this TV is negative.
3. If yes, then I add it to our ans variable, which is keeping track of the total money that Bob makes. At the same time, I decrement m.
4. We keep doing this till m becomes 0 or the loop gets over, and at last, we print ans .

# Code

```java
import java.util.*;
public class Sale{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        int arr[]=new int[n];
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
        }
        Arrays.sort(arr);
        int ans=0;
        for(int i=0;i<n && m>0;i++){
            if(arr[i]<0){
                ans+=-arr[i];
                m--;
            }
            else{
                break;
            }
        }
        System.out.println(ans);
    }
}

```

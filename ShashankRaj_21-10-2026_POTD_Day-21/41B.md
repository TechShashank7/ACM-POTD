# Problem Name - Martian Dollar - 41B

# Description

Starting with the initial amount of bourles we had, i ran an loop to find the tatal no. of dollar we could buy with them at that day and the leftover bourles that will remain after transaction. Then for that i ran an another loop inside to check selling on which day will give us what no. of bourles finally in the end and updated the maximum of them each time we get a new one.

# Code

```java
import java.util.*;
public class MartianDollar{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int b=sc.nextInt();
        int arr[]=new int[n];
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
        }
        int maxMoney=b; //Current amount of bourles with which we are starting
        int dollar=0, leftover=0;
        for(int i=0;i<n;i++){
            dollar=b/arr[i]; //Dollars we culd buy at this price with bourles we have
            leftover=b%arr[i]; //Bourles left with us after transaction
            for(int j=i+1;j<n;j++){
                int finalMoney=arr[j]*dollar+leftover; //Total no. of bourles after selling
                maxMoney=Math.max(maxMoney, finalMoney); //Updating max bourles  if its greater than last transaction one
            }
        }
        System.out.println(maxMoney);
    }
}

```

# Problem Name - Elevator - 120A

# Description

I wrote an if-else statement that covers all 4 possible cases

# Code

```java
import java.util.*;
public class Elevator {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String door=sc.next();
        int rail=sc.nextInt();
        String str = "front";
        if(door.equals(str)){
            if(rail==1){
                System.out.println("L");
            }
            else{
                System.out.println("R");
            }
        }
        else{
            if(rail==1){
                System.out.println("R");
            }
            else{
                System.out.println("L");
            }
        }
    }
}

```

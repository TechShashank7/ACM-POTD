# Problem Name - Helpful Maths - 339A

# Description

I firstly extracted all the numbers given into an array and sorted it. Then i printed the sum with numbers in non-decreasing format.

# Code

```java
import java.util.*;
public class HelpfulMaths{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String num[]=sc.next().split("\\+");
        int nums[]=new int[num.length];
        for(int i=0;i<nums.length;i++){
            nums[i]=Integer.parseInt(num[i]);
        }
        Arrays.sort(nums);
        for(int i=0;i<nums.length;i++){
            System.out.print(nums[i]);
            if(i!=nums.length-1){
                System.out.print("+");
            }
        }
    }
}

```

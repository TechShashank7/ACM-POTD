# Problem Name - Forgotten Episode - 440A

# Description

I used the simplest approach here. I just calculated the total sum of all the elements given and subtracted it from the sum of n natural numbers to find the missing no. from the list.

# Code

```java
import java.util.*;
public class ForgottenEpisode{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        long n=sc.nextLong();
        long sum=0;
        for(long i=0;i<n-1;i++){
            sum+=sc.nextLong();
        }
        System.out.println((n*(n+1))/2-sum);
    }
}
```

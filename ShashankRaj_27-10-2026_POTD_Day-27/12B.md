# Problem Name - Correct Solution? - 12B

# Description

I first sorted all the digits in the given number in ascending order so that the smaller digits could come at the front and larger ones could go at the back. Then I counted the number of zeros at the start of the number, if any exist, and also the index of the first non-zero element that appears. Afterwards, I construct the smallest number by starting it with the first non-zero element we found at the index we stored, appending all the zeros we found at the start, and then continuing with the rest of the numbers by appending all digits in ascending order from the given digits. Also, for the case when all the digits in the number are zero, indeed the smallest possible number shall just be a single zero. We handled that case by checking if the count of zeros is equal to the length of the array. 

# Code

```java
import java.util.*;
public class CorrectSolution {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        char arr[]=sc.next().toCharArray();
        String m=sc.next();
        Arrays.sort(arr); //Sorting the digits in the number so that the smaller digit could come closer and larger digits could go further 
        int zeroCount=0; //Count of trailing zeros
        int firstNonZeroIndex=-1; //Index of first non-zero element 
        for(int i=0;i<arr.length;i++){
            if(arr[i]=='0'){
                zeroCount++;
            }
            else{
                firstNonZeroIndex=i;
                break;
            }
        }
        String n=new String(arr);
        if(zeroCount==arr.length){ //If the number contains just zeros, then the smallest possible number shall be just a single zero. 
            n="0";
        }
        else if(zeroCount>0){
            n="";
            n+=arr[firstNonZeroIndex]; //Bringing the element at the first non-zero index to be the first digit of the number 
            for(int i=0;i<zeroCount;i++){ //Appending all the starting zeros after this first non-zero element 
                n+='0';
            }
            n+=new String(arr).substring(firstNonZeroIndex+1); //Appending the rest of the elements accordingly In ascending order  to make the number smaller 
        }
        System.out.println(n.equals(m) ? "OK" : "WRONG_ANSWER");
    }
}

```

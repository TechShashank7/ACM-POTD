# Problem Name - Next Test - 27A

# Description

I firstly added all the elements in an arraylist and found the maximum of them. Then i ran an loop from 1 to max+1 and checked of any of them doesnt exist already in the list. If yes then print it and return. Otherwise it prints, max+1 since all the indices smaller than it already exist in the list.

# Code

```java
import java.util.*;
public class NextTest {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        List<Integer> list=new ArrayList<>();
        int max=Integer.MIN_VALUE;
        for(int i=0;i<n;i++){
            list.add(sc.nextInt());
            max=Math.max(max, list.get(i));
        }
        for(int i=1;i<=max+1;i++){
            if(!list.contains(i)){
                System.out.println(i);
                return;
            }
        }
    }
}

```

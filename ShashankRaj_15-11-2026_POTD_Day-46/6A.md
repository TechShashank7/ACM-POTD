# Problem Name - Triangle - 6A

# Description

Firstly for checking for triangle, i checked triangle inequalty (sum of any 2 sides shall be greater than third one) on all 4 possible combinations.
Ifn't, then for checking segment, i checked if triangle inequality holds for two cases and in one case sum of 2 sides is exactly equal to third one, on all 12 possibel combinations.
If thsi also doesn't satisfies then its impossible to create a triangle out of given sticks lengths

# Code

```java
import java.util.*;
public class TriangleA {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int a=sc.nextInt();
        int b=sc.nextInt();
        int c=sc.nextInt();
        int d=sc.nextInt();
        if((a+b>c && a+c>b && b+c>a) || (a+b>d && a+d>b && b+d>a) || (a+c>d && a+d>c && c+d>a) || (b+c>d && b+d>c && c+d>b)){ // Checking triangle inequalty on all 4 possible combinations 
            System.out.println("TRIANGLE");
        }
        else if((a+b==c && a+c>b && b+c>a) || (a+c==b && a+b>c && b+c>a) || (b+c==a && a+b>c && a+c>b) || (a+b==d && a+d>b && b+d>a) || (a+d==b && a+b>d && b+d>a) || (b+d==a && a+b>d && a+d>b) || (a+c==d && a+d>c && c+d>a) || (a+d==c && a+c>d && c+d>a) || (c+d==a && a+c>d && a+d>c) || (b+c==d && b+d>c && c+d>b) || (b+d==c && b+c>d && c+d>b) || (c+d==b && b+c>d && b+d>c)){ // Checking if there exists exactly 2 triangle inequality and one exact equality on all 12 possible combinations
            System.out.println("SEGMENT");
        }
        else{
            System.out.println("IMPOSSIBLE");
        }
    }
}

```

# Problem Name - Parallelepiped - 224A

# Description

I first found out the lengths of all the sides by multiplying two sides and then dividing by the third and taking square root. E.g. - Suppose sides are a,b,c and areas are x,y,z such that x=ab,y=bc,z=ca. Therefore xy/z=√((ab²c)/(ac)) Afterwards i took sum of all and multiplied by 4 to find the total sum of all the edges of the parallelepiped

# Code

```java
import java.util.*;
public class Parallelepiped {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int x=sc.nextInt();
        int y=sc.nextInt();
        int z=sc.nextInt();
        System.out.println(4*(int)(Math.sqrt((x*y)/z)+Math.sqrt((y*z)/x)+Math.sqrt((x*z)/y)));
    }
}


```

# Problem Name - Vasya the Hipster - 581A

# Description

The no. of days that Vasya will be able to wear different pairs depends on whats the minimum of either blue or red socks he available to make pair with another. Also from the remaining amount of socks, i divided it by 2 to get how many days that it will give pairs for.

# Code

```java
import java.util.*;
public class VasyaTheHipster {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int a=sc.nextInt();
        int b=sc.nextInt();
        System.out.println(Math.min(a, b));
        System.out.println(Math.abs(a-b)/2);
    }
}

```

# Problem Name - Pallindromic Strings - 108A

# Description

I started a loop and kept incrementing the min until it matched with the reverse of hour.

# Code

```java
import java.util.*;
public class PallindromicTimes{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String time=sc.next();
        int hour=Integer.parseInt(time.substring(0,2));
        int min=Integer.parseInt(time.substring(3,5));
        do{ //Keep incrementing minutes and check equality with reverse of hour until it satisfies 
            min++;
            if(min==60){
                min=0;
                hour++;
            }
            if(hour==24){
                hour=0;
            }
        } while(min!=(hour%10)*10+hour/10);
        System.out.printf("%02d:%02d", hour, min);
    }
}

```

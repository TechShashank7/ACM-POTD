# Problem Name - cAPS lOCK - 131A

# Description

I checked for both the flagged conditions and if anyone of them meet then i applied the necessary processing on word and printed it otherwise i printed it as it is.

# Code

```java
import java.util.*;
public class cAPSiOCK {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        String word=sc.next();
        if(Character.isLowerCase(word.charAt(0)) && word.substring(1).equals(word.substring(1).toUpperCase())){ //Checking if first letter is lowercase and rest are uppercase
            System.out.println(word.substring(0, 1).toUpperCase()+word.substring(1).toLowerCase()); //Printing with first letter uppercase and rest lowercase
        }else if(word.equals(word.toUpperCase())){ //Checking if word is completely uppercase
            System.out.println(word.toLowerCase()); //Printing after converting to lowercase
        }
        else{ //If none of the flagged conditions exist then print the word as it is
            System.out.println(word);
        }
    }
}

```

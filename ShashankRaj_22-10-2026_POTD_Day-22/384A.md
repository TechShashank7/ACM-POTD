# Problem Name - Coder - 384A

# Description

I just used one condition to check if the position is suitable for placing a coder or not i.e. (i+j)%2==0. This is because thi s condition guarantees that the positions choosen for the coders are preferrable such that no 2 of them come in adjacent proximity.

# Code

```java
import java.util.*;
public class Coder {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        char arr[][]=new char[n][n];
        for(int i=0;i<n;i++){
            Arrays.fill(arr[i], '.');
        }
        int count=0;
        for(int i=0;i<n;i++){
            for(int j=0;j<n;j++){
                if((i+j)%2==0){ //Placing coders at alternate positions so no 2 come in adjacent proximity
                    arr[i][j]='C';
                    count++;
                }
            }
        }
        System.out.println(count);
        for(int i=0;i<n;i++){
            for(int j=0;j<n;j++){
                System.out.print(arr[i][j]);
            }
            System.out.println();
        }
    }
}

```

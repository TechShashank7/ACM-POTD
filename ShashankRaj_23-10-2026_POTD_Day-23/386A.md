# Problem Name - Second-price Auction - 386A

# Description

I just found out the index of the maximum element in the array and printed it by incrementing 1 to it to get its position in the array. I then sorted the array and then printed the second maximum element, which is the second-last element present in it.

# Code

```java
import java.util.*;
public class SecondPriceAuction{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int arr[]=new int[n];
        int max=Integer.MIN_VALUE;
        int maxIndex=0;
        for(int i=0;i<n;i++){
            arr[i]=sc.nextInt();
            if(arr[i]>max){
                max=arr[i]; 
                maxIndex=i+1; //Position of the maximum bid in given array
            }
        }
        Arrays.sort(arr);
        System.out.print(maxIndex+" "+arr[n-2]);
    }
}

```

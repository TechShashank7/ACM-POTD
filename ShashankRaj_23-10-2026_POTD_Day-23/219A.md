# Problem Name - k-String - 219A

# Description

I maintained a hash map and stored the frequency of all the characters appearing in the given string. Then I checked whether a solution exists or not by dividing the count of all the characters by n and checking if it's completely divisible or not. If it's not, then I printed -1 and returned from there, since a solution doesn't exist in this case. If a solution exists, then for every character, I calculated the count of how many times it should appear in a single block. I then constructed that single block by repeating that character by that calculated count, and after repeating this single constructed block n times, we get our final pattern. 

# Code

```java
import java.util.*;
public class kString {
    public static void main(String[] args){
        Scanner sc=new Scanner (System.in);
        int n=sc.nextInt();
        char s[]=sc.next().toCharArray();
        HashMap<Character, Integer> map=new LinkedHashMap<>();
        for(char i : s){
            map.put(i, map.getOrDefault(i, 0)+1); //Appearing frequency of each character appearing in the given string 
        }
        for(char i : map.keySet()){ //Handling the case when a solution doesn't exist 
            if(map.get(i)%n!=0){
                System.out.println(-1);
                return;
            }
        }
        String ans="";
        for(char i : map.keySet()){
            int count=map.get(i)/n; //Count of how many times this character should repeat in a single block  
            for(int j=0; j<count; j++) { //Making that single block 
                ans+=i;
            }
        }
        for(int i=0;i<n;i++){ //Printing this single block n times 
            System.out.print(ans);
        }
    }
}

```

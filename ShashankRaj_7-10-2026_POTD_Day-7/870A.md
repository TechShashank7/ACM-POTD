# Problem Name - Search for Pretty Integers - 870A

# Description

I firstly found if any common elements are present in both list and if they do then i print the smallest one. Otherwise i construct the smallest no. by picking up smallest no. from both lists and checking both AB and BA digit order to see which is minimum and printing them.

# Code

```java
import java.util.*;
public class SearchforPrettyIntegers{
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        Set<Integer> list1=new HashSet<>();
        Set<Integer> list2=new HashSet<>();
        for(int i=0;i<n;i++){
            list1.add(sc.nextInt());
        }
        for(int i=0;i<m;i++){
            list2.add(sc.nextInt());
        }
        int min=Integer.MAX_VALUE;
        for(int i : list1){ //Checking and finding the smallest common element in both lists
            if(list2.contains(i)){
                min=Math.min(min,i);
            }
        }
        if(min!=Integer.MAX_VALUE){ //Printing it if it exists
            System.out.println(min);
            return;
        }
        int digit1 = Collections.min(list1);
        int digit2 = Collections.min(list2);
        System.out.println(Math.min(min, Math.min(digit1*10+digit2, digit2*10+digit1))); //If there's no common element then we print the smallest no. by choosing the smallest element from both lists and checking the minimum of AB as well as BA
    }
}

```

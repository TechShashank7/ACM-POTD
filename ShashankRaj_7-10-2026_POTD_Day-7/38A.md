# Problem Name - Army - 38A

# Description

I started a loop from current rank till the aspired rank and kept adding the time it takes to go from current rank to next succesive rank as given in the years[] array. Therefore, sum finally gives us the total time it takes to go from rank current rank to aspired rank.

# Code

```java
import java.util.*;
public class Army {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int years[]=new int[n-1];
        for(int i=0;i<n-1;i++){
            years[i]=sc.nextInt();
        }
        int a=sc.nextInt();
        int b=sc.nextInt();
        int sum=0;
        for(int i=a;i<b;i++){ 
            sum+=years[i-1];
        }
        System.out.println(sum);
    }
}

```

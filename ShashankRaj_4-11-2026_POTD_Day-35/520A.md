# Problem Name - Pangram - 520A

# Description

I first converted all the given characters to lowercase and then added them to a hash set to remove the duplicates and just check a single time whether the alphabet exists or not. Afterwards, for every English alphabet letter, I checked if it exists in the given characters. 

# Code

```java
import java.util.*;
public class Pangram {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        char s[]=sc.next().toCharArray();
        Set<Character> set=new HashSet<>();
        for(char i : s){
            i=Character.toLowerCase(i);
            set.add(i);
        }
        for(char i='a';i<='z';i++){ // For every English alphabet letter, check if it exists in the given list of characters. 
            if(!set.contains(i)){
                System.out.println("NO");
                return;
            }
        }
        System.out.println("YES");
    }
}

```

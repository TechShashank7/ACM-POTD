# Problem Name - Comparing Strings - 186A

# Description

I firstly checked if lengths of both strings are equal or not because if not then it's impossible to make them equal by any no. of swaps. If they are equal then i started a loop from starting index and checked for the first unmatching character between both genomes and then did the same after starting a loop from ending index, and stored both indices in first and last variables. Then i performed the swap between both characters at first and last index in first genome. Then finally i checked if both genomes are now equal and if not then it means that just one swap is simply not enough to make them equal.

# Code

```java
import java.util.*;
public class ComparingStrings {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        char genome1[]=sc.next().toCharArray();
        char genome2[]=sc.next().toCharArray();
        if (genome1.length!=genome2.length) { // If both genomes have different length then it's impossible to make them equal by any no. of swaps
            System.out.println("NO");
            return;
        }
        int first = 0, last=0;
        for(int i=0;i<genome1.length;i++){
            if(genome1[i]!=genome2[i]){
               first=i; // Storing the index of first unmatched character between both genomes
               break;
            }
        }
        for(int i=genome1.length-1;i>=0;i--){
            if(genome1[i]!=genome2[i]){
               last=i; // Storing the index of last unmatched character between both genomes
               break;
            }
        }
        //Swapping the positions of unmatching characters in genome1 
        char temp=genome1[first];
        genome1[first]=genome1[last];
        genome1[last]=temp;
        if(Arrays.equals(genome1, genome2)){ // If a single swap was enough to make both genomes equal, print YES otherwise NO
            System.out.println("YES");
        }
        else{
            System.out.println("NO");
        }
    }
}

```

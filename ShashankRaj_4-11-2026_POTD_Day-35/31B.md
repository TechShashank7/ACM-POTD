# Problem Name - Sysadmin Bob - 31B

# Description

I first perform some checks to see if a solution even exists or not:
1. I checked if there are characters existing before the first @ and after the last @, because if there aren't, then we can't form any valid email address.
2. I added the index of all the @ symbols from the given string in a list and then checked if the size of the list is zero or not. If it's zero, then there is no @ existing in the given string, and if no @ exists in the given string, then of course we can't form any valid email address from it.
3. I checked if the distance between any two adjacent @ symbols in the string is at least 3 because if it's less than 3, then we can't form a valid email address from it because we can't distinguish between two email addresses properly.

Afterwards, i start distinguishing between all the email addresses and printing them. I started by initializing a variable `last` to keep track of the position of the last character of the current email address. I started a loop to iterate over the positions of all the @'s in the given string.

In each iteration, I printed the current email address character by character. After that, I checked if this current index is the position of the last @ or not. If it is, then we shall print all the remaining characters after it and exit the program. Also, before updating the `last` variable, I checked if we are currently at the position of the last @ or not because if we are, then there is no need to update the last variable, because we now just have to print the remaining characters after the last @. 

# Code

```java
import java.util.*;
public class SysadminBob {
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        char s[]=sc.next().toCharArray();
        if(s[0]=='@' || s[s.length-1]=='@'){ // We couldn't find any solution if there exists no character before first @ and after last @. 
            System.out.println("No solution");
            return;
        }
        List<Integer> index=new ArrayList<>();
        for(int i=0;i<s.length;i++){ // Storing the position of all @ in the given string 
            if(s[i]=='@'){
                index.add(i);
            }
        }
        if(index.size()==0){ // We can't form any valid email address if there is no @ in the given string. 
            System.out.println("No solution");
            return;
        }
        for(int i=0;i<index.size()-1;i++){ // No solution is possible if the distance between any two consecutive @ is less than 3. 
            if(index.get(i+1)-index.get(i)<3){
                System.out.println("No solution");
                return;
            }
        }
        int last=0; // To keep track of thep osition of the last character of the current email address  
        for(int i=0;i<index.size();i++){ // Iterating  over the position of all the @
            for(int j=last;j<=index.get(i)+1;j++){ // Printing the current email address character by character 
                System.out.print(s[j]);
            }
            if(i==index.size()-1){  // If the current index is the position of the last @ on the right, then we shall print all the remaining characters after it. 
                for(int k=index.get(i)+2;k<s.length;k++){
                    System.out.print(s[k]);
                }
                return;
            }
            if(index.get(i)+1!=s.length-1){ // Checking if we are currently at the position of the last @ before updating last variable
                last=index.get(i)+2;
                System.out.print(",");
            }
        }
    }
}
```
